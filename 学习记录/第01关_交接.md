## 一、这一关讲完了什么

### 1.1 读原始 pkl（`src/wafer_vlm/lswmd.py`）

- **要解决的问题**：`LSWMD.pkl` 是 Python 2 / pandas 0.x 时代序列化的，**现代 pandas 打不开**
- **核心代码**：`lswmd.py:87` `load_lswmd_frame()`；`:66` `install_legacy_pandas_shims()`；`:26-41` 旧类名映射表；`:47` `_new_Index`；`:99` `encoding="latin1"`
- **结论**：
  - pkl 里存的不是数据本身，是**"重建说明书"**（类名 + 属性路径）
  - 老 pandas 写的是 `pandas.indexes.*`，**pandas 1.0 把这个包删了** → `ModuleNotFoundError`
  - 修法：**在 `sys.modules` 里凭空造出这个模块**，指到现代的类上（`types.ModuleType` + `setdefault` 幂等）
  - `_new_Index` **这个名字不能改** —— 名字写在 pickle 字节流里，属于**外部契约**
  - **为什么不降级 pandas**：老版本在 Python 3.12 上编译不过（`lswmd.py:8-11` 注释原文）
  - `latin1` 是**无损搬运**（字节↔码点 1:1），UTF-8 会直接报错

### 1.2 挑样本（`prepare_data.py:36` `choose_indices`）

- **要解决的问题**：原库 81 万片，全用太贵，而且**类别极不平衡**
- **结论**：
  - **每类上限 800，`none` 上限 400**（`--per-class` / `--none-limit`）
  - **800 是"上限"不是"配额"** —— 实测：`Donut` 555、`Near_full` 149 是**全库都拿来还不够**；`Edge_Ring` 库里有 9680 只取 8%
  - **丢弃 79% 无标签的**：全库 811,457 → 有标签 172,950 → 抽样 5,904
  - ⚠️ **`none` ≠ "没标签"**：`none` 是**显式标注"这片是好的"**（库里 147,431 张，只取 400）；"没标注"是另一回事
    - `utils.py:60-67` `normalize_label()` 三种输出：`None`（没标注）/ `"none"`（好片）/ 具体类别
    - `utils.py:70-79` 注释解释了为什么用列表推导而**不用 `pandas.Series.map`** —— pandas 3.x 会把 `None` 改写成 `NaN`，**把两种语义悄悄合并**

### 1.3 按 lot 切分（`utils.py:82-93`）

- **要解决的问题**：分 train / val / test，且**同一批次不能跨份**（否则模型"认批次"而不是"认缺陷"）
- **核心代码**：`utils.py:82` `stable_bucket()`（3 行）+ `:87` `split_for_lot()`（6 行）
- **结论**：
  - **机制：sha256 分桶**。`sha256(f"{seed}:{lot}")` → 取前 8 字节 → `% 100` → 桶号
  - 桶号 `0-79` → train，`80-89` → val，`90-99` → test ⇒ **这就是 80/10/10 的由来，不是"取前 80% 数据"**
  - **为什么用 hash 不用 random**：hash 是**纯函数**，只需要"这一个批次名"这一个输入 —— 不看别的批次、不看总数、不看顺序
  - **random 的问题**：数是发给**位置**的（不存在第 1 个调用永远得同一个数，但**谁站在第 1 个位置**取决于名单顺序）
    - 实测：把一个 3822 批次的名单**反过来**，随机数分法有 **1290 个批次（33.8%）换了 split**；hash 分法 **0 个**
    - 可运行实验：`学习实验/随机分法实验.py`
  - **代价**：按批次分出的**样本数**不保证正好 80/10/10（实测 80.0/10.1/10.0，因为批次够多）
  - **硬检查**（`prepare_data.py:113-123`）：算三份的批次交集，有交集就 `raise`（**不是 print 警告**）
    - 为什么纯函数还要检查：**函数正确 ≠ 这次运行的产物正确**（换种子、手改、新老产物合并都会破）
    - 实测：`manifest_summary.json` 的 `lot_split_intersections` 三个都是空数组
    - 另有一个**独立的外部检查器** `code/tools/leak_check.py`（185 行）+ `results/reports/leak_check.json`（`passed: true`）
      - 它区分**样本泄漏**和**批次泄漏**，理由是："样本交集为零是必要的，但不充分"
      - 它有一张白名单 `ALLOWED_OVERLAPS = {("grpo","train")}` —— **预期内的重叠单独记录并写明理由**，意外的一律 fail

### 1.4 算几何特征 + 渲染成图（`utils.py:106-236`）

- **要解决的问题**：把一片 26×26 的矩阵，变成**一张给模型看的图** + **一堆给规则用的数字**
- **总览图**：`../.hermes/diagrams/1.4总览.html`
- **结论（两条支路互不相干）**：

**支路 A · 渲染成图**（`utils.py:231-236`）
  - `0→黑` `1→绿` `2→红`，放大到 448×448，**必须用 `NEAREST`（最近邻）**
  - **为什么必须最近邻**：这是**离散的 BIN 图，没有"半个红"**。双线性能算出**5730 种不存在的颜色**（实测），等于给模型看假信息；最近邻只有 **3 种**
  - 可运行实验：`学习实验/放大对比.py`（输出 `nearest_vs_bilinear.png`）
  - **放大的两个目的**：① 统一尺寸（248 种 → 1 种）② **让一个 die 占够像素**（17.2 px）**跟模型的 patch（16 px）同量级**
  - 顺带：**拉伸不会让晶圆变形** —— 非黑区域本来就是正方形（实测各种矩阵形状的外接矩形宽高比**全部 1.00**），空白边吸收了拉伸

**支路 B · 算数字**（四段）
  1. **去噪**（`:106` `isolated_point_filter`）：3×3 卷积数邻居，`neighbours <= 1`（周围没有别的坏点）判为噪点 → 改成好片
     - ⚠️ **只改计数，不改图**：图用原图渲染（`prepare_data.py:92`），去噪只影响 `features`
     - 三个数**全留着**：`raw_defect_count` 126 / `defect_count` 114 / `filtered_points_removed` 12（§5.2「禁止静默覆盖」）
  2. **拟合圆心**（`:115` `fit_wafer_circle`）：**纯数学，大模型零参与**
     - 取晶圆**外轮廓点** → **代数圆拟合**（把圆方程变形为线性方程 $x^2+y^2=Ax+By+C$）→ 一次最小二乘解出
     - 实测：`wafer_center_xy = [12.487, 12.518]`（26÷2 = 13 → 圆心在网格中心 ✅，**证明是矩阵坐标系不是图像坐标系**）
     - **传原图不传去噪图**（`prepare_data.py:154`）：**轮廓在外圈、噪点在内部**，去不去噪对轮廓无影响
  3. **归一化坐标**（`:184-189`）：
     - `x = (cols - cx)/radius`；`y = (cy - rows)/radius`（**y 轴要减反**，行号往下增大）
     - **`angle = arctan2(x, y)`** —— 正常写法是 `(y, x)`，**调换后 0 = 12 点钟、顺时针增加**，一行解决钟点方向
  4. **21 个特征**（`:145` `calculate_static_features`）：分五类（计数 5 / 位置 6 / 尺寸 2 / 分布 6 / 形状 1 / 状态 1）
     - `status` 实测分布：`ok` **5902** · `filtered_empty` **2**

### 1.5 `build()` 全貌与写盘时机（`prepare_data.py:49-138`）

- **结论**：
  - **切分不是一个独立步骤**，它是**循环里的一环**（`:82-105` 每圈做三件事：渲染图 → 算 split → 算特征）
  - **写盘顺序**：`source_stats.json`（`:75`，**渲染之前**）→ 循环里每圈写 1 张 PNG（`:92`，已存在就跳过 = 断点续传）→ **全部检查通过后**才写 `manifest.jsonl`（`:124`）→ `manifest_summary.json`（`:135`）
  - **`raise` 排在 `write_jsonl` 前面** ⇒ **永远不会存在一份"带着泄漏的 manifest"**
  - `write_jsonl` 是**原子写**（`utils.py:266-273`）：先写 `.tmp` 再 `replace`
