## 1. 题面复述

**我的建议命题：不再购买教师写的描述，允许使用已经公开的类别标签，从未经过本项目训练的模型出发，只靠类别对错的奖励训练，能否保留教师方案相对起点的大部分提升，并值得付出训练成本？**

先解释术语：给模型示范正确答案、让它照着学，叫监督微调（SFT）；让模型自己回答、按分数调整，叫强化学习（RL）。“直接”只表示跳过本项目的 SFT，不表示模型从未接受过上游训练。

我主张先换成上述问法，**暂不把严格零标签 RL 作为主实验**。省钱不必等于丢弃免费的已有标签；程序能算几何量，也不等于能可靠判断缺陷类别。若 mentor 要的确实是“训练完全不用已有类别标签”，本主实验不能回答它，须走附录乙的另一条路线，不能事后换名。

① **事实**：教师用量有记录，金额没有；原数据已有可信来源标记的类别，旧 RL 实际就在用它（`docs/FINAL_REPORT.md:49–52`；`code/tools/build_grpo_dataset.py:35–40`）。② **解释**：“免新增教师描述”是目前最有用、成本最清楚的版本。③ **未证实**：“教师很贵”的货币量级，以及“部署禁止外部模型”的正式约束，所查项目决策未给出；本稿把后者作为待确认条件，所有推理对照均设计为本地运行。

## 2. 目标刻度

取“答对比例”即分类准确率。草稿基准起点 (B=54/252=0.214286)，教师方案 (S=157/252=0.623016)，出处分别是 `results/reports/qwen35_9b_zero_shot__report.json:5–6`、`results/reports/qwen35_9b_adapter__report.json:5–6`；已从逐条回答复算。

**新增解释，尚非 mentor 确认：**若口语的 20、80 是这两个锚点，则

\[
T=B+\frac{70-20}{80-20}(S-B)
=\frac{54+(5/6)\times103}{252}=0.554894。
\]

即旧草稿上至少答对 **140/252**，约 **55.56%**，才越过连续阈值 **55.49%**。不能只算 (S\times70/80)，因为那样保不住“基座 20”的锚点。若原意是“准确率 70%”，那是另一目标，本稿没有把它偷换成较低门槛。

正式审核若改了标签，或换到新考卷，**固定上述公式，重测 B、S 后重算 T**；不能把旧分数搬过去。若 S 不再可靠地优于 B，刻度失效，停止解释“70 分”。

## 3. 现有证据

① **能核对的事实**：当前保留的交付模型是 SFT；分类最高单次成绩是 `GRPO_lr1e5_s3` 的 **162/252**，对 SFT 的配对检验 (p=0.301758)，不能说可靠胜出。两者不是同一个“最好”（`docs/LIMITATIONS.md:402–404`；`results/reports/qwen35_9b_grpo_lr1e5_seed3409__report.json:5–6`；`results/reports/seed_variance.json:105–107`）。旧 RL 从 SFT 产物开始，不能回答直接从基座训练的问题（`code/projects/wafer-defect-vlm/scripts/24_train_grpo.sh:76–77`）。

四个奖励的真实行为如下；这里的“答案字段”指机器可读取的键值文本，即 JSON：

| 奖励 | 实际判什么，哪里会失真 |
|---|---|
| 类别 | 文本与已有类标完全一致才得分；并非无标签。见 `code/tools/wafer_grpo_plugin.py:94–105`。 |
| 格式 | 只数规定字段是否存在，空值也能满分；不检查语义、类型或是否只输出一个对象。见同文件 `109–120`。 |
| 径向 | 与几何字段字符串相等；缺少目标时恒给满分。该字段原先测的是缺陷质心所在区域。见同文件 `132–144`；`docs/LIMITATIONS.md:770–782`。 |
| 钟点 | 允许循环距离相差一个钟点；目标缺失或为 `all/none` 时恒给满分。不是严格钟点相等。见同文件 `151–166`。 |

② **机制解释，有证据但因果未闭合**：同一道题的多个答案全得同分时，算法无法靠相对名次强化某个答案。旧运行格式分几乎饱和、类别答案常已正确，组内差异更多落在钟点；奖励方向与最终分类目标并不完全一致（`results/reports/grpo_reward_trace.json:5–26`）。但不能把这直接说成全部失败的唯一原因。

① **纠正一个机制误读**：零奖励差异不等于没有任何梯度。限制模型偏离参考模型的惩罚项，叫 KL 约束，仍可能更新参数；旧曲线第一步奖励差异为零，梯度范数却非零（`results/curves/qwen35_9b_grpo_v1.jsonl:1`）。

① **验收阻塞项**：人工双审未完成，基准仍是草稿；本次重新统计，两张表的审核字段仍全空（`benchmark/metadata.json:3–24`；`benchmark/review/status.json:11–12`）。本机只能读代码、复算已有回答；没有模型权重，服务器当前关机（`AGENTS.md:508`；`HANDOFF.md:29–40`）。

## 4. 实验序列

**以下步数、工期及预算均为乙的新增提议，耗时与效果未核实；具体配置、记账和停止规则在附录。此刻只提交方案，不启动实验。**

**第一步：修好判卷合同。** 双人审旧卷，另准备从未参与本轮选模型的新批次确认卷；固定题面、解析、坏回答计错规则。只改变审核状态及新卷来源，不据模型错题挑样本。需要公开数据、工程人员、两名审核者，不用显卡；两人并行审核及准备数据暂估 4～6 个工作日，人工量见成本节。允许结论：“这张卷子的定义可用”；不允许：“模型已通过正式验收”。

**第二步：验证奖励接线。** 从公共训练清单直接取图片和原类标，避开教师筛过的样本名单。奖励只判断类别，模型输入只给图片与问题。开机后先用 **20 条**跑 **2 步**，再逐类小样本检查；同时重测基座和旧 SFT 的固定题面。固定模型版本、图片、问法及精度，只检查能否正确读图、判分、更新；预计 **2 GPU 小时**。允许：“路径能跑、吞吐已测”；不允许：“短测证明会收敛”。

**第三步：做同信息量的对照。** 两臂均从相同基座开始：R 臂以类别对错做 RL；L 臂把同一类别直接作为 SFT 答案。已有教师 SFT 作为参照，不新增教师调用。固定图片集合、逐次出题顺序、输入、可训练模块、精度；主要变量是如何使用同一答案，算法特有参数分别锁定。各跑 **3 个种子**，R 每次最多 **1500 步**，L 匹配实际图片呈现次数；约 **26.69 GPU 小时**。允许比较“在本预算内哪种训练更值”；不能由 R 对旧 SFT 的差异单独归因算法，因为旧 SFT 的数据与任务也不同。

**第四步：锁模型后揭卷。** 全部候选均使用预先指定的最终检查点，报告所有种子。比较原图、去掉缺陷信息后的图和固定的另一种问法，测准确率及每类同等权重的综合分（macro-F1）。同一模型只改变图像条件或问法；预计 **6 GPU 小时**，另需审核者处理分歧。允许判断分类保留率、图像依赖与稳定性；不允许扩张成“描述、检索、生产泛化全成功”。旧卷结果只作历史桥接，新卷才作确认。

## 5. 成功判据

先写死，不按结果改：正式确认卷上，R 的每个种子点估计达到第 2 节的 T；平均成绩超过 T 的差值，其 **95% 不确定区间下界大于零**；macro-F1 也保留基座到旧 SFT 提升的 **5/6**。计算以同批次晶圆一起抽取，避免把同批次当独立证据。细则见附录丙，均为新增判据。

这叫**目标达成**，不自动叫“RL 更有价值”。后者还需 R 相对 L 的配对差值下界大于零，并报告额外 GPU 成本；没有胜出，就选更便宜且达标的 L。各类成绩全部报告，不只看挑出的困难类。

区间上界仍低于门槛，判本预算内未达标；区间跨门槛，判证据不足。程序故障、缺权重、人审未完成归为未完成，不能记零分或理论失败。

**假成功的样子**：训练奖励上升而新卷不涨；只输出高频类；去掉缺陷像素后成绩不变；换个预定问法增益消失；拿格式满分当能力；只报最好的种子。必须区分：若模型可靠学会了简单规则，它仍然学到了东西，只是没有证明 RL 比便宜方法更划算。

历史锚点：旧 RL **150 步用 2414 秒**，旧 SFT **7892 秒**（`results/reports/grpo_train_result.json:5–10`；`results/reports/sft_train_result.json:4–10`）。按这些锚点外推，主线约 **34.69 GPU 小时**，申请上限 **40 GPU 小时**，只串行使用现有单卡；这是估算，开机测吞吐后再核预算。

## 7. 我不同意的地方

**“几何分类器超过 SFT，所以几何已经是信息上限；特定几类必须涨才算视觉理解”不成立。** 本次复现了 **168/251**，但那个分类器用训练标签拟合，而且几何量本来就来自图像。这证明一种便宜方法有效，不证明能力上限，更推不出只检查指定类别就能做因果归因（`HANDOFF.md:117–141`；`学习记录/几何verifier复算_20260927.md:113–118`）。应放进同卷对照，而非当否决规则。

**“旧 RL 无效的机制已经完全定位”过强。** 常数奖励不提供自身的相对信号，但向整组加常数并不压低其余奖励的方差；零优势也不是零梯度。旧运行还从 SFT 出发，不能据此否定从基座开始。源码、曲线与本次反例见附录甲。

**“macro-F1 不能配对检验”不成立。** 它不能直接套逐题对错的检验，但可以对两个模型共同抽取相同样本、每次重算完整分数再相减；仓库自己的评分器已经能对它重采样（`docs/LIMITATIONS.md:299`；`code/projects/wafer-defect-vlm/src/wafer_vlm/evaluate.py:69–80,102–106`）。

**一次多抽几个答案的命中率，不是训练后成绩的硬上限。** 这种“抽 k 次至少一次答对”的量叫 pass@k。九选一均匀瞎猜 **16 次**也有 (1-(8/9)^{16}\approx84.81\%\) 命中；它不能证明看懂图。文献已联网核对，原文也讨论随机猜中问题，见附录戊；本稿不用低 pass@k 宣布 RL 不可能。

### 甲四：可重跑的核心核对片段

在仓库根目录运行以下 Python。只读文件、不生成缓存或输出文件；需 numpy。它验证奖励、常数平移、审核表及目标算术，其他两项复算方法见上。

```python
import ast, csv, json, math
from pathlib import Path
import numpy as np

p = Path('code/tools/wafer_grpo_plugin.py')
t = ast.parse(p.read_text(encoding='utf-8'))
t.body = [n for n in t.body if not (
    isinstance(n, ast.ImportFrom) and n.module == 'swift.rewards')]
ns = {'ORM': object, 'orms': {}}
exec(compile(t, str(p), 'exec'), ns)
rows = [json.loads(s) for s in Path('benchmark/structured.jsonl')
        .read_text(encoding='utf-8').splitlines() if s.strip()]
gold = [dict(r['gold'], clock_direction=r['gold'].get('clock_sector'))
        for r in rows]
answer = dict.fromkeys(ns['SCORED_FIELDS'])
answer.update(defect_type='Edge_Loc', radial_zone='center', clock_direction=6)
for cls, expected in [('WaferClass', 30), ('WaferFormat', 252),
                      ('WaferRadial', 210), ('WaferClock', 75)]:
    scores = ns[cls]()([json.dumps(answer)] * len(gold), gold)
    assert sum(scores) == expected
    print(cls, sum(scores), len(scores))
assert ns['WaferFormat']()(
    [json.dumps(dict.fromkeys(ns['SCORED_FIELDS']))], [{}]) == [1.0]
assert ns['WaferClass']()(['{}'], [{}]) == [1.0]
assert ns['WaferRadial']()(['BAD'], [{}]) == [1.0]
assert ns['WaferClock']()(['BAD'], [{}]) == [1.0]
r = np.array([0., 0., 1., 1.])
```

- L 学习率预设 1e-4；其余模型可训练部分、输入、数据出题顺序与 R 相同。L 直接学习类名，R 自己生成答案后拿对错分，二者无法拥有相同生成计算量。主要比较**相同原图呈现次数**的结果，并报告真实 GPU 时间；不能把差异说成只换了一行损失公式。

### 乙二：为什么不直接宣称严格零标签可做

已有类别是监督，教师筛选的样本名单也携带信息。即使删去类标，旧数据的按类别选样仍留下了标签参与的历史（`data/manifest_summary.json`、`docs/FINAL_REPORT.md:33–37`）。因此主线只能叫“免新增教师描述”，不能叫“完全无人提供类别信息”。

若人明确选择更强命题，**替代而非追加**主训练：从公共原始数据按不依赖类标的样本 ID 与 lot 选图；训练器不能读类标、教师产物或其接受名单。先在 CPU 上建设版本化的规则答题器 V(x)，它输出一个类别或拒答；奖励为 `合法答案且等于 V(x)`。这只是**规则伪标签**，不是真正无误的类别验证。缺陷比例等数学事实可精确计算，类别语义仍需另验。

先锁规则，再在独立开发集核对覆盖率、被接受答案的正确率，以及逐类误接受/误拒绝；人工核验条数、规则设计工时单列，不能隐去。允许拒答，但拒答样本不得冒充满分训练信号，也不能从最终全卷分母删除。通过标准及人工预算需要先确定，**本文没有已经验证的 V(x)，没有给该支线预批 GPU 预算**。

若 V(x) 合格，应成对比较“V 直接答题”“基座按 V 的奖励做 RL”“基座直接 SFT 学 V 的同一答案”，并用独立人审类别评测，不能只统计与 V 一致。若只奖励几何字段，却考九类分类，测到的是任务迁移；即使失败，也分不清是 RL 失败还是奖励根本没教类别。该分支当前适合先做奖励可行性研究，不适合承诺达到主线数字。

## 附录丙：评测、成功与失败的精确定义

**本节是新增预注册草案，待人确认，不是既有结论。**

1. **两张卷分工。** 旧卷经双人审核后重算，仍保留原版用于历史桥接；它已被反复分析，不能称全新盲测。确认卷拟每类 30 张、合计 270 张，来自与原 train/val/test 均不同、此前未参与教师筛选和模型选择的公共原始 lot。由审核者隐藏模型输出、独立给类别；分歧仲裁，无法确认则列 challenge，按预定 ID 顺序补足。若某类数量不足，先公开真实数量和功效限制，模型训练前修订方案，不能训练后挑卷。
2. **主指标。** 在新卷上令 B、S 分别为固定基座、旧教师 SFT 的准确率，R_j 为各随机种子的 RL 准确率。定义 (D_j=R_j-[B+5(S-B)/6])。同时对 macro-F1 做同形计算；不把旧卷的 0.554894 当新卷固定数字。旧卷 macro-F1 的相应历史阈值为 0.531969，由两份原报告 `:7` 推导，仅供解释。
3. **区间。** 使用“反复抽取同一批次、每次重新计算”的 lot cluster bootstrap，固定种子 3407、重采样 10000 次；每次对所有模型使用完全相同的 lot 抽样索引，带入该 lot 全部晶圆，并重算 B、S、平均 R 与 D。macro-F1 固定完整类别词表；缺类抽样仍按固定词表处理并披露频率。95% 区间取两端分位。3 个训练种子只报告均值、标准差、全范围；此区间条件于已经跑出的模型，**不是对无限次训练稳定性的保证**。
4. **成功要同时满足。** 各 R_j 的 D_j 均不小于 0；平均 D 的区间下界大于 0；macro-F1 的同形差值也满足两条要求。基座与教师 SFT 的差值下界必须先大于 0，否则双锚点解释不能成立。两指标须同时通过，不从多张表任选一个宣布成功。
5. **图像依赖守卫。** 对所有固定模型，把每张图红色缺陷格改成绿色，保留晶圆有效轮廓和分辨率；比较原图与该图在原标签下的成绩差，其下界须大于 0 才允许声称依赖缺陷信息。改图后的计分只是信息移除诊断，**不把原标签称为改图后的正确类别**，也不作为鲁棒性成绩。不能仅凭此证明模型学会全部视觉语义。
6. **经济价值另判。** 用相同抽样计算平均 R 减平均 L，区间下界大于 0 才说观察到 RL 的额外分类收益；否则只说没证明更值。L 达标而 R 不可靠胜出，优先交付 L；二者都不达标，保留旧 SFT，解释预算限制。几何分类器另作低成本参照，不能因它便宜就免去相同测试与错误报告。
7. **固定问法守卫。** 主问法与备用问法均在训练前锁定。备用问法的结果仅作敏感性报告：若主目标通过、备用问法不保留同样的相对增益，只能称“固定问法分类达标”，不能称可随意提问的通用模型。不能测试后选择问法或重新调阈值。
8. **报告边界。** 所有类别均报 precision、recall、F1、混淆表及样本数；拒答计错。旧 scorer 对结构化解析失败会跳行（`code/projects/wafer-defect-vlm/src/wafer_vlm/evaluate.py:129–150`），所以不把旧结构化分当本次主终点。描述、结构化、检索若仅复用旧产物，标历史结果；未跑的新模型任务写 `not run`。本主实验成功也只支持分类命题。

## 附录戊：文献核对与适用范围

本次联网读取 [arXiv:2504.13837v5 摘要](https://arxiv.org/abs/2504.13837v5) 及 [该版本正文](https://arxiv.org/html/2504.13837v5)，标题为 *Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?*。核对位置：正文关于 pass@k 的定义、与选最好答案及多数投票的区别，以及 **Random Guessing Issue** 段。

原文将 pass@k 用于研究“多次采样能否覆盖正确解”，明确区别于实际选出正确答案；也讨论猜中但推理不正确的问题。它对所研究训练设置的观察，不能升级为所有模型、所有奖励、所有训练的数学不可能定理。本任务只有九个类别，猜中的问题更突出：均匀独立猜测下，pass@8 = 0.610256，pass@16 = 0.848099，均由 (1-(8/9)^k) 推导；这是反例算术，**不是本项目模型实测**。
