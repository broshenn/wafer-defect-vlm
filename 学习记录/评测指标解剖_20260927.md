# 评测指标解剖：Caption 那三个数到底在数什么（2026-09-27）

本文件记录一次对 **Caption 评测指标**的逐行解剖。起因是学生问「空回答率、根因幻觉率是什么」，
读代码时发现这三个指标**全都是"关键词有没有出现"级别的判据，不是"描述得对不对"**。

沿用本项目纪律：**能核对的事实 / 解释（可能错）/ 未证实未测量** 三层分开。

---

## 一、三个指标的精确定义（能核对的事实）

全部来自 `code/projects/wafer-defect-vlm/src/wafer_vlm/evaluate.py:157-180` 的 `caption_metrics()`。

### 1. 空回答率 `empty_rate`

```python
text = row["response"].strip()
if not text:
    empty += 1
```

**就是把回答去掉首尾空白，看是不是空字符串。** 没有任何语义判断。

SFT 实测 = **0.0**（`results/reports/qwen35_9b_adapter__report.json` → `caption.empty_rate`），
即 252 条里每一条都至少说了点什么。

### 2. 根因幻觉率 `root_cause_hallucination_rate`

```python
if any(term.lower() in text.lower() for term in rubric["must_avoid"]):
    hallucinated += 1
```

比对的词表来自 `benchmark.py:25`：

```python
FORBIDDEN_TERMS = ["污染", "光刻", "蚀刻", "设备故障", "工艺原因",
                   "contamination", "lithography"]
```

**七个词全是「工艺原因」词。回答里只要出现任何一个，就记一次"幻觉"。**

**为什么禁它们**：数据集只有"是什么缺陷"的标签，**没有根因标签**（`AGENTS.md` §5.6
「没有可靠根因标签时，不创建根因问答」）。模型说出根因 = 无依据的编造。

### 3. must-hit 命中率 `must_hit_rate`

```python
if any(term.lower() in text.lower() for term in rubric["must_hit_any"]):
    hits += 1
```

词表来自 `benchmark.py:16-24` 的 `SHAPE_TERMS`，**按类别给两个词，命中任意一个即算过**：

| 类别 | must_hit_any |
|---|---|
| Center | 中心 / 团簇 |
| Donut | 环 / 圆环 |
| Edge_Loc | 边缘 / 局部 |
| Edge_Ring | 边缘 / 环 |
| Loc | 局部 / 团簇 |
| Near_full | 满圆 / 大面积 |
| Random | 随机 / 散点 |
| Scratch | 线 / 划痕 |
| none | 无缺陷 / 正常 |

## 三、三个问题（能核对的事实 + 我的解释）

### 3.1 `none` 的 11.5% 很可能是**度量的产物**，不是模型的问题 【事实 + 解释】

`none` 的命中词是 `["无缺陷", "正常"]`。SFT 实际写出来的回答是这样的：

```
晶圆中心区域存在少量随机分布的缺陷点，整体缺陷密度低，无明显聚集或特定形状。
晶圆边缘区域存在稀疏、断续的缺陷点分布，无明显特定角度聚集。
晶圆中心区域存在少量随机分布的缺陷点，整体缺陷密度低，无明显聚集或特定形状。
```

**这些描述是正确的** —— "整体缺陷密度低""无明显聚集或特定形状"就是在说"没有系统性缺陷"。

但它们**不含连续子串「无缺陷」**（"无明显聚集"≠"无缺陷"），**也不含「正常」**。⇒ 判成未命中。

**[事实]** 26 条 `none` 里有 23 条被判未命中，逐条看内容，**没有一条是"答错了"**。
**[解释，可能错]** 所以这 11.5% 主要反映的是**用词差异**，而不是描述能力。

### 3.2 词表本身有冗余和过宽 【事实】

**冗余**：`Donut` 的词表是 `["环", "圆环"]` —— **"圆环"已经包含"环"**，列出两个等于只列一个。

**过宽**：`Edge_Loc` 和 `Edge_Ring` 的词表**都含"边缘"**。实际统计（同一批数据）：

| 类别 | 靠哪个词命中 |
|---|---|
| Edge_Loc | 靠 `[边缘, 局部]` 21 条；**只靠 `[边缘]` 9 条** |
| Edge_Ring | 靠 `[边缘, 环]` 28 条；**只靠 `[边缘]` 2 条** |
| Donut | 靠 `[环]` 22 条；未命中 8 条 |

**`Edge_Loc` 有 9/30 的命中，只靠"边缘"这一个词。** 而"边缘"在晶圆描述里几乎是万能词 ——
**这 9 条算不算"命中了形态"，存疑。**

### 3.3 幻觉率的 `0` 分不清两件事 【事实 + 解释】

**[事实]** 回答长度中位数（我从 `results/raw_outputs/` 现算）：

| 模型 | caption 回答长度中位 |
|---|---|
| 基座（零样本） | **580 字符**（最长达 973，带 markdown 标题、分点、分隔线） |
| SFT 之后 | **56 字符**（最短 43，最长 76） |

幻觉率从 **0.2183 → 0**（基座 55/252 命中禁止词）。

**[解释，可能错]** 判据是"整条回答里有没有出现那 7 个词"。**56 个字符的回答，本来就没地方放这些词。**
所以这个 `0` **无法区分**：
- (a) 学会了不臆测根因
- (b) 只是话说短了

### 3.4 被禁词的例子（真实的基座回答）

命中 `['污染','光刻']`：

> ……此类缺陷可能源于制造过程中的颗粒**污染**、**光刻**掩模瑕疵或检测噪声，需结合工艺背景进一步分析。

命中 `['污染']`：

> ……可能对应于制造过程中的全局性**污染**、沉积不均或刻蚀损伤等宏观缺陷类型。

对照，未命中的一条：

> 主要缺陷表现为分散于全晶圆的红色像素化斑块，其中右下角区域缺陷最密集、规模最大；
> 最大缺陷簇尺寸约为 0.25R × 0.20R……

**区别很清楚：前者说了"可能源于什么"，后者只说"长什么样、在哪里"。**

## 四、结论

**这三个指标都是"关键词有没有出现"级别的判据，不是"描述得对不对"。**

| 指标 | 数的是 |
|---|---|
| 空回答率 | 回答是不是空的 |
| 根因幻觉率 | 回答里有没有出现那 7 个词 |
| must-hit | 回答里有没有出现该类的两个词之一 |

**所以它们能反映的**：模型有没有说话、有没有说那几个特定词。
**不能反映的**：描述是否准确、是否完整、有没有编造**词表之外**的内容。

注：`caption_metrics` 自己的 `note` 字段也承认了这一点 ——
`"shape/location/size boundary cases still require the frozen human rubric review"`（`evaluate.py:179`）。
但那个**人工双审至今没做**（`benchmark/review/` 两张表全空），所以这句话目前是空的。

### 对 RL 的直接影响 【解释】

`重做计划/00_TODO.md` 的 E1/E2 里，奖励**不含任何文本项**。原因现在更清楚了：
**文本这一侧没有可自动验证的判据** —— 用关键词匹配当奖励，会被"多写那几个词"直接攻击；
用另一个大模型当裁判，就变成了"用模型评判模型"。

## 五、复现脚本

```python
# cd "D:/pycode/晶圆图研究" && python 本脚本
import json, pathlib, re
SHAPE = {"Center":["中心","团簇"],"Donut":["环","圆环"],"Edge_Loc":["边缘","局部"],
         "Edge_Ring":["边缘","环"],"Loc":["局部","团簇"],"Near_full":["满圆","大面积"],
         "Random":["随机","散点"],"Scratch":["线","划痕"],"none":["无缺陷","正常"]}

lab = {}
for l in open("benchmark/core.jsonl", encoding="utf-8"):
    d = json.loads(l)
    lab[d["sample_id"]] = d["rubric"]["failure_type"]

rows = [json.loads(l) for l in
        pathlib.Path("results/raw_outputs/qwen35_9b_adapter.jsonl").read_text(encoding="utf-8").splitlines()
        if l.strip()]

def sid_of(r):
    im = r["images"][0]
    s = im if isinstance(im, str) else json.dumps(im, ensure_ascii=False)
    return re.search(r"(wafer_\d+_\d+)", s).group(1)

KEY = "客观描述主要缺陷"          # caption 任务的题干特征
stat = {}
for r in rows:
    if KEY not in "".join(m.get("content","") for m in r["messages"]): continue
    c = lab[sid_of(r)]
    resp = re.sub(r"<think\b[^>]*>.*?</think\s*>", "", r["response"] or "", flags=re.S)
    hit = any(w.lower() in resp.lower() for w in SHAPE[c])   # ← 逐类取词表，别用错类的
    h, n = stat.get(c, (0, 0)); stat[c] = (h + hit, n + 1)
for c, (h, n) in sorted(stat.items(), key=lambda kv: kv[1][0]/kv[1][1]):
    print(f"{c:<12} {h:>2}/{n:<3} = {h/n:.1%}")
```

> ⚠️ **写这段脚本时我犯过一次错**：把 `none` 的词表用到了所有类上，得到 "Donut 0/30、Center 0/30"。
> 差别在于 `hit = any(... in resp for w in SHAPE[c])` 这一行的 `SHAPE[c]` —— **必须是当前类别的词表**。
> 记在这里，是因为它正好是本项目反复出现的那个形状：**一个看起来正常的结果，其实来自工具的错误。**
