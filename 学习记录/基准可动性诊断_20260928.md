## 怎么读（三层，别混）

**【能核对的事实】** 在**这 12 个被评估的 run** 之间，164/252（65%）的题不携带区分信息 ——
要么所有 run 都对，要么几乎没有 run 对。剩下 90 题才是真正能把模型分开的。

**【解释，可能错】**
1. **这是"对这批模型"的判断，不是基准的永久属性。** 换个强得多的模型，那 75 道"太困难"
   里的一部分会变成可动。所以不能说"这些题没用"，只能说"**用现在这些 run 测不出差异**"。
2. **和"空转步"是同一个形状。** `01_实验策略_v2.md` §2 的 M3 记的是训练集上"组内奖励全同
   → 优势为 0 → 不产生梯度"，占 7%–42% 的步；这里是基准上"所有模型结果一样 → 不贡献信号"，
   占 65%。**同一件事的两个截面。**
3. **对噪声地板的含义**：0.0357 的极差是在 252 行上算的（≈9 行）。若只数那 90 道可动的题，
   同样的 9 行 = **10 个百分点**。所以"某个 run 比另一个高 9 行"这句话，**在可动子集上并不小**。
   ⚠️ 这一条要再算一遍才算数（还没做）。

**【未证实 / 未测】**
- 基座的**逐题**输出我只用了 1 次采样（`zero_shot` 是贪心式单次），**不是 pass@k**。
  所以这里说的"可动"**不是** M2 要测的那个东西 —— M2 测的是"同一题多采几次能不能采出正确
  答案"，这里测的是"**不同模型的单次结果会不会不同**"。**两个不同的量，别混。**
- 这 90 道可动的题，**是不是集中在某几个类**、是不是就是我们判据 Q 里的 H 集 —— **没算**。

## 对计划的直接含义

1. **M2 的产出要加一列**：不只是"基座 pass@8 = 多少"，还要给出**"基座 pass@8 = 0 的题清单"**。
   按 overtraining 那篇（arXiv 2606.15455），把更新集中在这类题上才可能把 pass@256 抬起来。
2. **报分数时要说明"在哪些题上"** —— **订正后的说法**：不存在一个放之四海皆准的"死重比例"，
   它**随你比哪两个模型而变**：
   - 对**全部 12 个 run**：零信息的是 97 题（38%）
   - 对**基座 vs SFT 这一对**：**139 题（55%）两者结果相同**，只有 113 题在区分它们
   - 对 **SFT vs 某个 RL run**：尚未算（下一步该补）

   **所以"涨了 5 行"这句话的分量，取决于你在数哪一批题。** 报告里应该同时给
   「252 行」和「参与该比较的题」两个分母。**这件事要在商讨实验方案时定**（四个目标里的第 4 个）。
3. **报增益必须固定并公开 prompt 格式** —— 那条预印本批评说，各 arm 用自己最优格式时，
   MATH-500 的 pass@1 增益从 +36.50 缩到 +12.27 个百分点。

## 追问：「太困难」的 75 道，是标签有问题还是题真的难？（2026-09-29 补）

**由头**：学生复述时把「对错结果一样」说成了「答案一样」—— 这个不精确的说法带出一个真问题：
「都答错」有两种，含义完全不同。

- **12 个模型都给同一个错答案** → 可能是**标签错了**或题本身有歧义
- **12 个模型各错各的** → 题就是难

**结果**（同样用 `evaluate.py` 的判分、同样 12 个 run）：

| | 题数 |
|---|---|
| 几乎都给**同一个错答案**（判据：非 INVALID 的答案只有 1 种，且 ≥11/12 一致） | **2 道** |
| 各错各的 | **73 道** |

**那 2 道**（值得人工看一眼）：

```
wafer_00044283_021   12/12 都答 Edge_Ring   gold = Edge_Loc
wafer_00045569_009   12/12 都答 Random      gold = Donut
```

**【能核对的事实】** 75 道「太困难」里只有 2 道呈现「全体一致地错」的形状。

**【解释，可能错】** 所以「太困难」这 75 道**不是标签质量问题**，是题真的难。这反过来说明：
它们是 RL 真正该攻克的前沿，而不是该被清理的脏数据 —— 与 overtraining 那篇说的
「零成功的题」正好对上（见上「对计划的直接含义」第 1 条）。

**【未测】** 这 2 道到底是不是标签错—— **需要人看图判断**，本机不能定。即便两道都错标，
对 252 行头条数字的影响是 2/252 ≈ 0.8 个百分点，不改任何已成立的结论。
**它们该进人工双审的清单**（`benchmark/review/` 那两张表本来就要逐行看）。
