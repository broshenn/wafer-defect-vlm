### 4.1 `FINAL_REPORT.md` §6c 把「已测出的值」印成 `not run`

- **现象**：§6c 的三行（`centroid` / `mean_radius` / `outer_extent`）在 `GRPO_lr1e5` 及其后 9 列全写 `not run`，但 `results/reports/radial_zone_audit.json` 的 `runs.grpo` **有这三个值**（0.2698 / 0.4444 / 0.4206），`LIMITATIONS.md` §6.7 的表也照实印了它们。

## 五、三类分开（面试口径）

### 能核对的事实（当场可翻）

- 数据：5904 / 3822 lot / 4721·594·589 / 跨划分 0；7 类各 800、Donut 555、none 400、Near_full 149；全部图 448×448 且只有黑绿红三色；`label_source` 100% `ground_truth`，无 `predicted_type`。
- 基准：252（Near_full 16 / none 26）、90 query、22505 qrels；`draft_pending_human_review`、`gold_withheld: true`、252 条未审；检索相关性 0/1/2 只有 1.9% 是 2。
- 训练：QLoRA r16/α32/dropout0.05/冻结 ViT+Aligner/lr 1e-4；604 步、eval_loss 0.4692→0.2800、峰值 32.92 GiB；**实际 1.5 epoch**（配 2，`max_steps` 截断）。
- 主表：Base 0.2143 / macro-F1 0.1347 → SFT 0.6230 / 0.6114；12 个 run 的最高准确率是 **162/252**（`GRPO_lr1e5_s3`，与 SFT 的 157/252 差 5 行）；幻觉率 0.2183→0；检索 mAP@10 0.3236→0.3873（SFT）／0.4337（GSPO_G32 最高）。
- 统计：lr 5e-5 在 GRPO 与 GSPO 上**都显著低于** SFT（p=0.0436 / 0.00032）；lr 1e-5 的 run 与 SFT 不可分（p=1.0 / 0.81）；IS 层级的**唯一单变量**对照不可分（Δ=−0.0317，p=0.268）；组大小在本设计里从未单独变过（有效批次 = 组大小²）**且**在三档上都不显著。
- 噪声地板：三次抽样极差 **0.0357 ≥ 阈值 0.0278**，规则事前注册。
- 失败分类：`LIMITATIONS.md` §8 的 20 条，逐条核对下来 **17 条修复完全在场**，3 条部分在场（见 4.7a/b 与 §8 第 5 条：记录改了、脚本没改），1 条有残留字面量（`radial_zone_audit.py` docstring 仍写 0.063/83.7%）。

### 解释（可能错，错了要改口）

- 「SFT 涨 40 个点」主要是**格式与任务对齐**，不是视觉能力的 40 个点：换成训练格式提示词，同一模型在同一批 252 行上是 **0.8849**（诊断，不作榜单）。而基准数字受提示词不一致影响，是**下界**。
- `radial_zone` 的低分**主要反映标签退化**（用质心判带），不是模型看不见位置；换位置判据后 SFT 0.2640→0.4560，但仍低于新下限 0.5079 ⇒ 正确说法是**接近随机**。
- `clock MAE` **条件于一个更容易的子集**，且 12 个 run 的计分行数从 176 到 208，**任意两个 run 都不在同一批行上**（文档只写了 SFT 与 GRPO 这一对不可比）。
- caption 幻觉率归零**无法区分**「学会不臆测根因」与「学会了说短句」：长度中位从 562 字符掉到 30–41 字符，而判据是「整条回答里是否出现根因词」。（另有 3/55 例是否定式误报，修正后 52/252 = 0.2063。）
- 训练奖励与基准成绩**负相关**（10 个 RL run 上 r ≈ −0.397）：奖励涨得最多的 `GSPO_G32`（+0.385）基准上掉得最狠（−0.0711）。这更像**奖励代理与目标任务脱钩**，而不是「RL 没用」。
- 三次抽样极差 ≥ 阈值 ⇒ 「学习率效应与种子噪声不可分」；但那只覆盖 `GRPO G=4 lr1e-5` 这一个格子。
