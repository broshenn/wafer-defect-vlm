## 项目是什么

用 Qwen3.5-9B + ms-swift，对 WM811K 晶圆 BIN 图做 QLoRA SFT，再做 GRPO/GSPO 强化学习后训练，
在自建 benchmark `wafer_bench_v1` 上评五类任务（分类 / 结构化字段 / Caption / 鲁棒性 / 检索）。

**一句话结论**：真正有效的是 SFT（分类 **21.4% → 62.3%**）；RL 那 10 个实验**没有一个显著超过 SFT**。

## 环境边界（先看这个，否则会白干）

- **服务器 = AutoDL 实例，目前已关机**。项目根 `/root/autodl-fs/wafer-vlm`。
- **本机没有权重**（约 119 G），也没有原始教师产物 ⇒ **不能重训、不能重跑完整评测**。
- 本机**能**做：只读审计、读代码与文档、用 `results/raw_outputs/` 重算指标、跑不需要 GPU 的分析。
- 环境里**没有装 vLLM**，rollout 只能用 `TransformersEngine`（慢）—— 这是新计划最大的实际瓶颈。
