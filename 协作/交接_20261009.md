## 七、会咬人的坑（**都踩过**）

1. **上传会静默写 0 字节且不报错** ——
   `run_on_school.sh -c "cat > 路径" < 本地文件` **不工作**（stdin 被内部通道占了）。
   必须用 `upload.sh` / `upload89.sh`，**且传完核字节数**。
2. **服务器上没有 `/WS` 目录** —— 那只是文档别名，真实路径在仓库外。
   脚本用 `${WS_ROOT:-/WS}`，实际跑时要么设 `WS_ROOT=<真实根>`。
3. **`git push` 的代理端口每次不一样** —— 用前先测 `7890` / `10808` 哪个活。
   2026-10-09 实测：**7890 通、10808 不通、直连 github 失败**。
   命令：`git -c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890 push origin main`
4. **复核材料必须先把结构定死再收集** ——
   我**两次**栽在"六个复核会话各写各的 JSON 结构"上，第二次每模型只统计到 60 项（应 180）。
   **正确做法**：先冻结输出 schema、跑回归，**汇总时先规范化并自检总数**。
5. **别用自由文本正则给描述结论打分** —— Codex 明确禁止。
   正确做法是**只接受枚举值**（`SUPPORTED`/`PARTIAL`/`CONTRADICTED`/`UNCERTAIN`），
   在 `协作/02_ClaudeCode_实操/百炼多模型业务对照_20261009_1203/复核schema_冻结.py` 有现成的。
6. **别拿一个任务的成绩去说另一个任务** —— 类别高不等描述高（本轮实测分开了）。
7. **`python` 的 `/tmp` ≠ Git Bash 的 `/tmp`** —— 前者是 `D:\tmp`。传文件前看清。
8. **A100 会间歇性卡死**（`nvidia-smi` 返回码 0 但零输出、UUID 查不到），
   但**会自己恢复**；卡死时不要反复探测（探测本身会堆积 D 状态进程）。
