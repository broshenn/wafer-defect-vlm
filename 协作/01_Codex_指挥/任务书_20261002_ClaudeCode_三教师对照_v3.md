## 2. 已完成什么，未完成什么

Codex 已查询百炼模型目录，以及 DeepSeek 官网模型目录和余额，均有 HTTP 200 的认证结果。DeepSeek 余额接口 `is_available=true`；私人余额金额不写进公开仓库，也不当作预算授权。

证据：`百炼只读接入核验_20261002.json` 与 `DeepSeek官网只读接入核验_20261002.json`。当前图片推理请求为零，模型声明支持图像不等于实际 PNG 调用通过。

官网当前来源：

- [模型列表接口](https://api-docs.deepseek.com/api/list-models)：目录包含模型版本、输入模态和输出上限。
- [Vision](https://api-docs.deepseek.com/guides/vision)：`deepseek-flash` 支持图片与文本，示例以 Base64 image_url 发送图像字节。
- [价格](https://api-docs.deepseek.com/quick_start/pricing)：官网与百炼计费分开；高峰/非高峰、缓存命中/未命中及输出单价须按真实时段和币种核对。不能从“Flash”或余额可用推断本轮免费。

历史 AGENTS §5.4 的官网只验证文本是旧状态，不是“官网不支持图像”的证明；本轮只核到目录及官方说明，实际图像请求仍 not run。

## 3. 执行与预算

沿用双教师任务同十八张原图、提示词 v2、检查器 v3。每个模型第一张先跑一次，通过后直接继续本模型余下十七张。**每模型最多十八次，共最多五十四次图片尝试**；只要费用守卫允许才能发下一次。新增候选不自动增加金额预算，既有总费用上限问题仍待用户回答。

每次独立上下文，仅当前图片和固定提示词；不提供原类别、几何结果、批次构成或前图回答。默认思考设置及其差异如实披露，不把 Qwen 的 `enable_thinking` 套到 DeepSeek。共同输出预算和超时按接口支持与费用验证后事前锁定，不失败后扩额。客户端自动重试=0，不补写 JSON、不换图。

单模型错误停止该模型，另外两模型在预算有效时可继续；指纹/泄露标签/总预算错误全停。保留截断、超时、失败及未执行数。总尝试上限是工作量限额，不冒称费用硬上限。

学校端执行规则不变：公开数据上传与指纹核验、选样/转换、图片API对照、学生训练在学校环境完成；Windows 不回退执行训练相关数据处理。当前 SSH 第一跳未通过，需先取得受支持的可执行接入；不从网页 Cookie 获得执行权限。标签 SFT 不依赖教师选定，可并行准备。
