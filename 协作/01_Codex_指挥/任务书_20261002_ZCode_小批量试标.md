签发：**Codex，2026-10-02**。状态：**待 Claude Code 准备清单、Codex 验收并锁定输入路径后执行**。由用户转交触发，不由其他 Agent 自动启动。

## 1. 目的、预算与入口

验证原位置自动读图、逐张回答与保存流程，以及类别、定性形态/位置描述的可靠性。不是正式全量标注、模型能力对比或尺寸能力验收。

只使用用户已有的 ZCode 客户端 **GLM-5.3-Flash** 套餐，不接外部 API，不调用 WorkBuddy，不切换供应商或付费模型，不用 computer-use。后端身份无法核验时继续注明“客户端声明”。

标注上限 **9 张，每张一次尝试，按清单顺序**；先完成清单前 3 张。它们都成功保存完整且格式合法的答案，才在同一已批准清单内继续余下最多 6 张；否则立即停止。本轮不重试、不换图片补齐、不扩大数量。该上限是控制工作量的预算，不等于 token 或货币成本上界。

额度由用户在客户端手动记录任务开始与结束的套餐余量、时间与模型显示名，不需要手动附图。无法取得额度时如实写未提供，可完成这个固定数量的功能测试，**不得估算单张成本或还能标多少张**。套餐用尽、触发付费、限流或要求升级时立即停止。客户端内部回合与重试不可设置时如实披露，不能宣称后端仅请求一次。

## 3. 执行流程

1. 用新的 ZCode 客户端对话，确认当前 GLM-5.3-Flash 套餐，不沿用已看过其他模型答案的会话。生成参数取不到写未提供，不填入 WorkBuddy 旧参数。
2. 按盲清单逐张用客户端视觉工具读取原位置 PNG；一次只看一张，不复制、搬动、拼图，不用几何程序或另一个模型代答。可获取的工具名称与证据保存下来；取不到日志就写未提供。
3. 每张仅作一次回答。先将原始最终答案逐字保存到自己目录，再运行离线格式校验，不能根据标签或检查结果重写答案。
4. 七字段齐全、枚举/类型正确；本轮额外核对 `extent_r` 为 null。失败、空回答、截断、无法看图或格式失败立即停，保留失败记录。`unknown` 是允许的不确定答案，不因不是预期类别而重试。
5. 如果同一个客户端对话顺序处理多张，明确记录后续上下文可能包含前图与前答；不称为相互独立的单次 API 调用。完成全部原始回答固定后，才交由 Codex 复核；批次中途不接收类别纠正反馈。

本轮输出定性描述，不验证数值尺寸。提示词与首轮不同，不能用成功率或速度差宣称新版本质量提升。
