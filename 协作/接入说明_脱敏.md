## 一、结构：两跳

```
本机（Windows）
   └─ SSH ─→ macOS 跳板机（Tailscale 地址，仓库外）
                ├─ SSH ─→ school-A100    内网地址，仓库外
                └─ SSH ─→ 5090 那台       内网地址，仓库外
```

**跳板机是必经之路**（学校机器不可直接到达）。
**跳板机会掉线**（笔记本睡眠 / 网络切换），掉线时所有服务器操作都会失败；
恢复后重试即可 —— **不要误判成服务器故障**。

## 二、脚本（**别自己重写**）

全部在仓库外 `D:\pycode\.ssh-tmp\`：

| 脚本 | 用途 |
|---|---|
| `run_on_school.sh` | 在 **A100** 上跑命令 |
| `hop89.sh` | 在 **5090** 上跑命令 |
| `upload.sh` / `upload89.sh` | 传文件到 A100 / 5090 |
| `askpass.sh` | 跳板机口令（SSH_ASKPASS 自动读，无需直接调） |

**优先用「命令写进文件」而不是 `-c '命令'`** ——
命令里带中文、引号、换行、`$` 时 `-c` 很容易被 shell 吃掉字符。

### ⚠️ 坑一：上传可能**静默写 0 字节**

`run_on_school.sh -c "cat > 远端路径" < 本地文件` **会失败且不报错** ——
该脚本的 stdin 被 base64 通道占用，本地 stdin 到不了远端。
**上传必须用 `upload.sh` / `upload89.sh`，且每次上传后核字节数**：

```bash
n=$(stat -c %s 本地文件)
bash upload89.sh <远端绝对路径> < 本地文件
m=$(bash hop89.sh -c 'stat -c %s <远端绝对路径>' | tr -d '\r' | tail -1)
[ "$n" = "$m" ] && echo OK || echo "不一致 $n vs $m"
```

### ⚠️ 坑二：服务器上**没有 `/WS` 这个目录**

`/WS` 只是**文档别名**，真实根是私人路径。
仓库里的脚本用 `${WS_ROOT:-/WS}` 取根，所以实际跑时要
`WS_ROOT=<真实根> bash 脚本.sh`，或把脚本里的路径改成真实的。

## 五、跑 GPU 任务的固定规矩

1. **父 shell 先锁卡**：`export CUDA_VISIBLE_DEVICES=<UUID>`，
   **必须在 Python 启动之前设**，进程内再设没用。
2. **确认真单卡**：断言 `torch.cuda.device_count() == 1`。
3. **先识别故障卡**：UUID 查询返回空的是坏卡，跳过。
4. **不与他人进程共用卡**；**不建占位进程**。
5. **长任务用 `setsid nohup ... & < /dev/null`**，否则 SSH 一断任务就死。
6. **设备分钟按「逐卡占用区间并集」记**，不是「卡数 × 墙钟」。

## 六、仓库操作

- 仓库**是公开的**
- **push 要走代理，且哪个端口活着每次不一样**，用前先测：

```bash
timeout 10 bash -c 'cat < /dev/null > /dev/tcp/127.0.0.1/7890' && echo 7890活
timeout 10 bash -c 'cat < /dev/null > /dev/tcp/127.0.0.1/10808' && echo 10808活
```

- 提交前**扫敏感串**：账号名、内网 IP、口令、key、真实根路径

## 七、纪律（**不能破**）

- **不伪造**人工审核、API 结果、训练结果或指标；**`not run` 不是 0**
- **不杀别人的进程**、不改共享配置、不扩 GPU 预算
- 结论分三层：**能核对的事实 / 解释（可能错）/ 未证实未测量**
- 只写自己的新目录；**旧产物只读**
- 预测与实测分开报；**不拿一个任务的成绩去说另一个任务**

## 八、一步验证

```bash
cd <仓库外脚本目录>
bash hop89.sh -c 'hostname; nvidia-smi --query-gpu=index,memory.free --format=csv,noheader | head -3'
bash run_on_school.sh -c 'hostname; nvidia-smi --query-gpu=index,memory.free --format=csv,noheader | head -3'
```

两条都返回主机名和显存，说明两跳链路与两个账号都通。
