# 03 · ZCode（标注）

> **地盘规则**：这个目录里只放 ZCode 的标注产物。其他 agent **不往这里写**。
>
> ZCode 是**在客户端里对话**执行的（不是 API）。产物由用户在 ZCode 会话里生成，落到本目录。

## 这里放什么

| 类型 | 说明 |
|---|---|
| **原始回答** | 逐字节保存，文件名带样本 ID |
| **格式校验记录** | JSON 解析、七字段、枚举/类型检查的结果 |
| **交付报告** | 环境、输入、时间线、原始回答、校验、用量、约束遵守 |
| **失败记录** | 空回答、截断、离线 —— **不覆盖历史尝试** |

## 每个交付必须写清的六件（照 `重做计划/04` 的执行要求）

1. **客户端版本、套餐名称、模型显示名**；**后端实际模型标识取不到就写"未提供"**
2. **图片指纹**（sha256）、**视觉输入方式**、**实际输入提示词及指纹**
3. **原始最终回答** + JSON/字段校验结果 + **停止原因**
4. **起止时间、耗时**；客户端给的输入/输出/推理用量与结束原因，**没有就写"未提供"**
5. **调用前后额度与查询时点** —— 区分会话总消耗与单张用量；分账不可得就写"未提供"
6. **产物路径** —— 并**明确标为"模型标注"**

## 三条硬要求

**① 只读一次、只标一次。**
同一图片**一次尝试**。失败、空回答、截断**立即停**——不重试、不换模型、不扩大样本。

**② 不许向标注模型泄露答案。**
- 不读取原始类别标签、历史模型对这张图的推断、含类别的样本清单
- **不向标注模型提供选图观察、几何程序结果或预期答案**

**③ 看不到图就停。**
只读取路径、文字或文件属性**不算看图**。
若图像由**另一个视觉模型**解读后再送进来，**如实报告组合链路**——不能称为"原生看图"。

## 不能声称的事

- **"真人专家标注"或"人工复核"** —— 模型生成的一律记"**模型标注 / 模型复核**"
- **"格式通过 = 内容正确"** —— 格式校验与事实正确性**分开报告**
- 把 Kimi 的产物归成 GLM 的结果（或反之）

## ⚠️ Claude Code 补核的结果（2026-10-02，**不是 ZCode 做的**）

用 `data/manifest.jsonl` 里的可信标签对了一遍：

| 字段 | GLM-5.3-Flash | 真值 / 几何 | |
|---|---|---|---|
| `defect_class` | `Center` | `Center`（`label_source: ground_truth`） | ✅ |
| `radial_zone` | `center` | `center` | ✅ |
| `extent_r` | **0.65** | 几何算的 **1.989** | ❌ 差 3 倍 |

**尺寸那个分歧，模型自己在 `uncertainty` 里预判到了**（"周围散点是否计入主要簇无法确定"）——这是好现象。

**但这一张说明不了视觉能力**：`Center` 是几何召回 **0.90** 的类，**不看图也可能答对**。
