## 一、更正我上一轮的一句错话

我此前写「**无法从实例内部关机**」——**这是错的**。

- `/usr/bin/shutdown` **确实存在**，是平台包装命令（205 字节 ASCII 脚本，`/usr/bin/shutdown:` 后接
  清理回收站 → 往 PID 1 打日志 → `kill` 掉 supervisord 的全部进程）。
- 也就是说，**从容器内部执行 `/usr/bin/shutdown` 是可以关机的**，Codex 的判断正确。

## 四、给用户/Codex 的关机方案

待 **LabGuard 线任务结束后**（或用户明确同意打断它），在实例内执行：

```bash
/usr/bin/shutdown
```

预期行为：清回收站 → 向 PID 1 打一行 `user execute shutdown command in container!` → kill supervisord。
**关机不等于释放**：数据留在磁盘上；**停止进程也不等于平台停止计费**，账单仍需用户在控制台核对。
