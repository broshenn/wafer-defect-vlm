# 几何参考的 train 侧交叉诊断（程序 × 人工看图）

> 目的：验证 `几何参考_v2.py` 的测量在**真实图**上是否可信，并确定方向判据的阈值。
> **本诊断全部在 train 侧样本上做**，未使用 36 图 / 56 图候选 / 确认池来调任何阈值。
> 图是看的，结论分三层：**看到的 / 程序算的 / 两者是否一致**。

## 一、轮廓（圆心与半径）—— 5904 张全量实测

| 指标 | 实测 | 结论 |
|---|---|---|
| 反解往返一致 | **5904 / 5904** | PNG ↔ 矩阵无损，测量与模型看到的图等价 |
| `hint`（manifest 记录的原生尺寸）命中 | 5904 / 5904 | 反解快路径全部走通 |
| 矩阵边长范围 | 22×50 ～ 122×104（另见 212×84 一例） | 非方阵普遍存在 |
| 椭圆「漏」（有效格落在椭圆外）| 最大 4.45%，中位 0.000 | 外接框椭圆是良好模型 |
| 椭圆「洞」（椭圆内是黑格）| 最大 17.9%，中位 1.48%，>5% 有 41 张 | 残差来自原图圆盘在格点上的量化 |
| 轮廓异常（>10%） | **2 / 5904** | 阈值只捕捉严重非椭圆/截断 |

**看图确认**：晶圆在矩阵坐标里是**椭圆**（45×48 的图，外接框半轴就是 22.5 / 24），
所以归一化必须按半轴分别除，否则角度会算歪。归一化后 `r=1` 就是晶圆边缘。

## 二、方向判据：为什么最后选了最保守的那套

### 2.1 看过的三组图（联系表在 `诊断_*.png`）

| 组 | 内容 | 我看到的 | 程序判的 | 一致？ |
|---|---|---|---|---|
| A（8 张） | 方向合格样本 | 每张都有一个**紧凑小团块**位于某个钟点位置 | `single`/`axis`，扇区与团块方位对得上 | ✅ |
| B（8 张） | 当时的「模糊带」（R1 0.41–0.50） | 大片红覆盖半个晶圆，**说不出一个钟点** | `unknown` | ✅ |
| C（8 张） | 明确 `none` | 环状 / 全片散布 / 无方向 | `none` | ✅ |
| D（8 张） | `Scratch` 且当时判 `none` | **肉眼能看出斜向划痕** | 当时判 `none` → **不一致** | ❌ **真问题** |
| E（10 张） | 收窄后的模糊带（R1 0.20–0.30、无线状结构） | 有的像「底部单一方向」，有的纯散布 | `unknown` | ⚠️ 半数可说 single，半数不可 |

### 2.2 由 D/E 两组改掉的两个设计

**（1）整图 PCA 不能用来判方向。** 最初用「红点云的主轴各向异性比 λmin/λmax」判线状。
实测发现：一张**清晰的过中心竖线**因为叠加了边缘红圈，λmin/λmax 高达 **0.79**（看着像各向同性）。
散点云同样能被环状淹没。→ **改成绕晶圆圆心的角向统计量 R1/R2**，质心角度只留作诊断字段。

**（2）「稳健线状结构检测」被降级为诊断。** 我实现了一个自由偏置的直线带检测器
（180 个方向、滑窗直方图、带内点数 × 跨度填充度打分），想用它把 D 组认出来。
**实测它分不开细线与实心团块**：

```
mass_frac >= 0.25 且 fill >= 0.55 且 span >= 0.6 时
  Center 3 张、Donut 0、Edge_Loc 45、Edge_Ring 0、Loc 28、Random 0、Scratch 155、none 0
```
一个实心盘的中央带同样有高占比与高填充度（`Center` 类 `mass_frac` 中位数 0.15、`fill` p90 0.90）。
→ 它**不参与给出方向**，只在谐波很低但检出线状结构时**否决 `none`**（改记 `unknown`）。

### 2.3 最终阈值（来自 train 侧逐类分位，写死在代码里）

```
R1 ≥ 0.60                       → single
R2 ≥ 0.70 且 mean_r ≥ 0.25      → axis
R1 < 0.20 且 R2 < 0.30 且无线状 → none
其余                            → unknown
```
依据：`Center` R1 p99 = 0.27、`Edge_Ring` 0.31、`Random` 0.38、`Near_full` 0.19 ——
「本来就没有钟点方向」的类别，R1 的 p99 都在 0.38 以下，所以 0.60 的单向下限取在它们之外。

### 2.4 代价（必须一起说）

这套保守规则让**全量 5904 张里只有 1.5% 有方向参考**（`single` 62 + `axis` 27），
`unknown` 占 30.2%。这是**数据的性质**，不是判据的缺陷：
在 100～1000 个散布红点、外加一圈边缘红 die 的图上，「缺陷集中在几点钟」本来就不成立。
按合同「方向模糊就记 unknown、不强塞答案」，宁可只对少数样本给出可信方向。

## 三、其他字段的 train 侧诊断

| 字段 | 检查 | 结果 |
|---|---|---|
| `coverage_level` | 档位分布（中位 18%、P95 60%）；档位边界 ±0.004 内的样本 | 边界样本 278/5904 = 4.7%，已在参考里标 `coverage_band_edge`，评测时单列 |
| `red_mass_zones` | 三带质量占比；红格 <3 记 unknown | 组合分布合理（三带 2881、中+边 2481、仅边 500、中心+边 38…） |
| `defect_class` | 与公开标签对齐；标签与图冲突的样本 | **不改标签**；`none` 类语义是「无可辨图案」而非「零失效」，已按此修正模板句 |
| 单点 / 共线 / 无红点 | 合成用例 | 方向记 `unknown`（N<8 或 PCA 退化），区带记 `unknown`（红格<3） |

## 四、这轮诊断**没有**做到的事

- **不是人审 gold**：看图的是我（AI），不是人工标注员；意见分歧只记在这一节。
- **没有覆盖全部 5904 张**：只看过 42 张联系表（A–E 组）+ 统计分布；
  样本外的模式仍可能有未发现的失败。
- **theta 与栅格的对应关系未与原始 WM811K 定义核对**：本版的角度定义是**我们自己冻结的定义**
  （上方 12 点、顺时针、椭圆归一化），不声称等于原始数据集的方位口径。
