> 状态：**本版 schema 只另存新文件，不替换 v1 七字段题面、不重跑历史成绩。**
> 题面全文见 [`题面_prompt_v2.txt`](题面_prompt_v2.txt)；机器可读 schema 见
> [`schema_v2.json`](schema_v2.json)；奖励实现见 [`奖励_v2.py`](奖励_v2.py)（服务器上名为 `reward_v2.py`）。

## 一、为什么要换 schema（对着 v1 的真实阻断点）

v1 七字段（`defect_class / morphology / radial_zone / clock_direction / extent_r / caption_zh / uncertainty`）
里只有 `defect_class` 能机器判分：`extent_r` 被冻结检查器规定**必须填 null**（尺寸压根没进输出），
`clock_direction` 是**任意字符串**，其余是自由文本。所以"多字段 RL"在 v1 上没有可发奖励的字段。

v2 的做法**不是**去解析自由文本，而是把要奖励的量**改成受约束枚举**：

| v1 字段 | v2 字段 | 变化 |
|---|---|---|
| `radial_zone`（6 值，单值） | `red_mass_zones`（center/middle/edge 的有序去重列表或 "unknown"） | 允许多区带；语义从"缺陷在哪"改成"红点**质量**落在哪些径向带" |
| `clock_direction`（任意字符串） | `direction_type` + `clock_sectors`（1–12 整数） | 受限语法，无自由文本可解析 |
| `extent_r`（必须 null） | **无此字段** | 尺寸本轮**不进**主奖励，先定义测量对象 |
| `morphology` | 并入 `caption_zh` | 自由文本不参与奖励 |
| （新增） | `coverage_level` | 红 die 占（红+绿）的档位 |

## 二、七个字段的定义与取值

| 字段 | 取值 | 参考怎么算 |
|---|---|---|
| `defect_class` | 九类之一或 `"unknown"` | **公开标签**（`manifest.failure_type`），来源不变；争议不由 AI 自动改标签 |
| `coverage_level` | `none / low / medium / high / near_all / unknown` | 红 die 数 ÷（红+绿）die 数：`none`=0；`0<低<5%`；`5%≤中<20%`；`20%≤高<50%`；`≥50%`=near_all。**黑色不进分母** |
| `red_mass_zones` | `["center","middle","edge"]` 的有序去重子集，或字符串 `"unknown"`，或 `[]` | 按归一化半径 r 分三带（r<1/3 中心、1/3≤r<2/3 中部、r≥2/3 边缘）；某带红点质量占比 ≥10% 且该带红点 ≥2 个才算"在"；红点总数 <3 → `unknown` |
| `direction_type` | `single / axis / none / unknown` | 见 §三 |
| `clock_sectors` | 1–12 整数列表；与 `direction_type` 联动 | `single`→恰好 1 个；`axis`→恰好 2 个不同整数；`none`/`unknown`→`[]` |
| `caption_zh` | 自由文本 | **不参与奖励**；只做 AI 复核，不称人工 gold |
| `uncertainty` | 自由文本 | 同上 |

**坐标口径（与冻结题面一致）**：图片上方 = 12 点、右方 = 3 点、顺时针；扇区 1 = `[0°,30°)`（12 点到 1 点）。

## 三、方向怎么判（三段判据，全在程序侧）

方向参考完全由**绕晶圆圆心的角向分布**（圆统计量 R1/R2）与一个线状结构诊断给出：

```
n_red < 8                                   → unknown   （证据不足）
R1 ≥ 0.60                                   → single    （单向集中）
R2 ≥ 0.70 且 红点平均半径 ≥ 0.25             → axis      （两瓣相对）
R1 < 0.20 且 R2 < 0.30 且 无线状结构          → none      （有把握说没有方向）
其余                                        → unknown   （模糊带）
```
（`R1 = |Σe^{iθ}|/N`，`R2 = |Σe^{2iθ}|/N`，θ 为绕晶圆圆心的钟点角。
`mean_r` 下限用于排除"红点全挤在中心、角度无意义"的退化情形。）

**为什么这么保守（本版最重要的一个实测发现）**：全量 5904 张上，坐标合格的方向只占 **1.5%**
（`single` 62 + `axis` 27）。逐类看：`Center`/`Edge_Ring`/`Random`/`Near_full`
几乎全部落在 `none`（正确 —— 环状与全局分布本来就没有钟点方向），
而**肉眼能看出划痕的 Scratch 样本，谐波常被「边缘红圈 + 散布红点」稀释到阈值以下**。
这类样本因此落进 `unknown`（**排除计分**），而不是被硬说成 `none`。

**被否掉的一个方案（留证）**：曾实现"稳健线状结构检测"（180 个方向的滑窗直线带，
用带宽内点数 × 跨度填充度打分，并打算用它判 `axis`）。**实测它分不开细线与实心团块**：
一个实心盘的中央带同样有高占比与高填充度（`Center` 类 `mass_frac` 中位数 0.15、`fill` p90 0.90）。
因此该检测器**只保留为诊断字段**（`direction.line_structure`），并只用于**否决 `none`**
（谐波很低但检测到线状结构时记 `unknown`，不敢断言无方向），**不用来给出方向**。

## 四、未知 / 不适用的处理（三处口径必须分清）

1. **模型答 `unknown`**：合法答案。**参考已知时按 0 分计**，不给部分分；参考未知时该项不参与计分。
2. **参考是 `unknown`**：该字段的权重归零，其余字段重新归一化。**不把"没测出来"当满分。**
3. **`[]` 与 `"unknown"` 不是一回事**：`red_mass_zones` 为 `[]` 表示"没有红点/没有区带"；
   `"unknown"` 表示"看不出来"。红点数为 0 时参考就是 `[]`，模型答 `"unknown"` 得 0。

## 五、明确**不做**的事

- **尺寸（extent）不进本轮主奖励。** 先要定义清"全部红色像素的归一化径向跨度"还是
  "主要线段/团块的范围"，两者不能混用。诊断值在 `几何特征表.extent_candidates`，**不是参考**。
- **不用自由文本正则给描述打分。** `caption_zh` 只做枚举式 AI 复核，另列报告。
- **不从标签反推几何答案。** 所有几何字段只由 PNG 反解出的矩阵计算，与 `failure_type` 无关。

## 六、与历史版本的关系

- v1 七字段题面、检查器、成绩、adapter **全部不动**；v2 的输出、数据、奖励、adapter 另存新目录。
- **两版成绩不可跨版比较**：题面与检查器 SHA 都变了，字段含义也变了。
- 旧 36 图 / 56 图已被看过并参与方案设计，**只作开发诊断**，不充当 v2 的独立最终考卷；
  v2 的留出卷是新冻结的 `确认池`（120 图，见 `数据池合同.json`）。
