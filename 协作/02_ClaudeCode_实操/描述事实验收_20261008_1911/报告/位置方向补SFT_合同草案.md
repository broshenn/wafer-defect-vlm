## 一、来源：能拿到什么、拿不到什么

### 1.1 候选来源

WorkBuddy（GLM-5.3-Flash）对训练缺口 1200 图的七字段输出。
落盘位置 `协作/04_WorkBuddy_复核/夜间主标_20261008_0301/GLM/`。

其中与「位置 / 方向」有关的是两列：

| 字段 | 题面要求的取值 | 实际观察到的取值 |
|---|---|---|
| `radial_zone` | `center / middle / edge / global / none / unknown` | **常用中文**（如「中心」「边缘」），审计报告称为「非字面 294/819」 |
| `clock_direction` | 可靠时写钟点方向，否则 **JSON `null`** | 混合：字符串钟点方向、字符串 `"null"`、真 `null` |

⚠️ **前提问题**：这两列**只存在于能解析成七字段的那批里**。
按 `B_WorkBuddy合并/独立复算_格式漂移.md`，当前唯一 item_id 1169 中：
- 纯文本非 JSON：**350 条**（自第 117 片起连续 50 片）→ **这两列根本不存在**
- 另 161 条 `raw_answer` 是对象、658 条是字符串内 JSON

**所以先要结算的是「到底有多少条真的带了可用格式的位置/方向」，而不是 1200。**

### 1.2 拿不到的

- **没有独立 gold**。WorkBuddy 的 `radial_zone` / `clock_direction` 是**模型标注**，
  不是人工真值，也不是几何真值。
- 项目里唯一现成的几何依据是 `features` 里的 `radial_zone` / `clock_sector`，
  但 **`radial_zone` 是质心定义**（`archive/local-skeleton/tools/radial_zone_audit.py`
  已记录），与「主要缺陷区域」不是一回事 —— **不能当 gold 用**。
- 旧教师结构化字段那三个已经被证明是**程序覆盖**的产物（见更正报告 §2），同样不能用。

## 二、适用性：这批数据能不能当 SFT 目标

### 2.1 能用的情况

只有当**目标字段本身可信**时才能做监督。逐项判断：

| 字段 | 可作 SFT 目标？ | 理由 |
|---|---|---|
| `radial_zone` | ⚠️ **存疑** | 无 gold；且模型输出中文、需映射；映射规则本身要写测试 |
| `clock_direction` | ❌ **不建议** | 无 gold；方向对旋转敏感、对 12 点钟基准敏感；本项目 §7.6 明确「旋转会改变钟点方向」 |
| `extent_r` | ❌ **不可用** | 题面**要求固定填 null**，所以它永远没有信息 |

### 2.2 因此，本轮真正可做的只有

**不是「补 SFT」，而是「先建立可核规则 + 合成测试」**，即 Codex 同时提到的后半句。
具体三件事：

1. **写清 `radial_zone` 的判定规则**：圆心/半径由有效轮廓拟合（AGENTS.md §6），
   径向直方图固定 `[0, wafer_radius]` 十个 bin，禁止用「缺陷最大半径」当终点。
   规则本身可以**用几何特征确定性算出**，**不依赖任何模型标注**。
2. **合成测试**：构造已知答案的合成晶圆（纯中心簇 / 纯环 / 纯边缘 / 无缺陷 /
   单点 / 共线点 / 拟合失败），断言规则输出正确。
3. **只在那之后**，才谈「用 WorkBuddy 的位置列做 SFT」——
   而且那时它是**学生模型的软目标**，不是 gold，**必须单独报告**。

| 项 | 数值 | 占比 |

**结论：位置/方向的可用量不是 1200，是 556（radial_zone）/ 433（clock_direction）。**
而且这 556 / 433 条**都没有独立 gold**（见 §四）。

⚠️ **另一件必须记住的事**：这 1200 图**本来就在训练池 3072 里**（交集 1200/1200，已核）。
所以「补 SFT 数据」实际是**给已有图换/加监督目标**，不是扩充数据量。
**必须防止同图两套冲突目标同时进训练集。**

## 四、缺 gold 怎么处理（**这是本合同的硬约束**）

1. **没有独立 gold 的字段，一律不进主评测**，只在 SFT 里当**软目标**，
   并在报告里标注「模型辅助候选，非真值」。
2. **缺值 ≠ 满分**。`clock_direction` 为 `null` 的样本，
   在奖励/评分里**不能算对**，只能算**未测**。
3. **`extent_r` 固定 null**，因此它**永远不参与任何评分**。
4. **不做多字段 RL**（本轮明确未放行）。Teacher 文字**不是**独立奖励 gold。
5. **格式检查 ≠ 内容正确**。机械检查只说明它是合法 JSON，
   **不能**宣称位置/方向说对了。
