## 0. 一句话

在公开晶圆 BIN 图上给 Qwen3.5-9B 做**冻结视觉侧的语言 LoRA SFT**：
未微调基座在严格 JSON 口径下九类识别 val84 为 **0/84**，
只用**公开类别标签**训 3072 张即到 **77/84（Macro-F1 0.922194）**。
同时用**逐图输入完全相同、只改监督答案**的对照，比较「只给类别标签」与
「类别标签 + 教师形态描述 + 中文 Caption」两种监督 ——
**加入描述监督在本开发集上没有带来类别收益**。

**描述本身（形态/位置/方向/Caption）的事实正确性尚未完成复核**，
本报告只在其完成范围内陈述。

## 14. **关于「真人复核」：本项目的性质声明（2026-10-08）**

**用户已明确决定：本项目不做真人复核。**

这一决定本身**完全有效** —— 项目做多少人工、花多少人力，是项目方的选择。
但它有一个**必须写下来的后果**，因为它决定了这份报告**能声称什么、不能声称什么**：

### 14.1 因此**永久**成立的限制

1. **所有「复核」都是模型复核草稿，不是人工 gold。**
   包括 36 图那 648 条判定 —— 执行者是与学生模型同源的 Claude 子agent，
   且**继承了编排会话的上下文**（知道项目在比 D 与 L）。
2. **`benchmark/` 保持 `draft_pending_human_review` / `gold_withheld: true`。**
   `benchmark/review/` 的两张 252 行表**每一列标签都是空的**，这一点不会改变。
3. **「本项目没有人工验证环节」会作为一条永久边界写在报告与简历里。**
   它不会因为时间推移而消失，也不会因为补充更多模型复核而消失。
4. **不得以任何方式把模型结果填进人工栏位**，或使用
   「人工双审 / 专家复核 / 已人工确认」这类措辞。

### 14.2 这不等于「结果不可用」

仍然**可以**如实主张的：

- **类别指标是硬的**：标签来自公开数据集的 `failure_type`（`label_source=ground_truth`），
  不是模型标注。val84 的 77/84 与 91.7% 是在这个基础上算的。
- **机械事实是硬的**：所有 sha256、行数、隔离检查、格式合规数，都可当场重算。
- **配对区间是硬的**：5000 次重采样给的是统计不确定性，与有没有人审无关。
- **模型复核是**诚实的证据**，只是它的证据等级**低于人工，且已披露其来源与局限。

### 14.3 一句话怎么对外说

> 本项目的类别结论建立在**公开数据集的原标签**上；描述事实部分的复核由**模型**完成，
> **未做人工复核**，这一限制在报告中持续标注。

**不要把「模型说没问题」说成「已确认」。**
