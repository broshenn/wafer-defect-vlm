## 0. 一句话

在公开晶圆 BIN 图上给 Qwen3.5-9B 做**冻结视觉侧的语言 LoRA SFT**：
未微调基座在严格 JSON 口径下九类识别 val84 为 **0/84**，
只用**公开类别标签**训 3072 张即到 **77/84（Macro-F1 0.922194）**。
同时用**逐图输入完全相同、只改监督答案**的对照，比较「只给类别标签」与
「类别标签 + 教师形态描述 + 中文 Caption」两种监督 ——
**加入描述监督在本开发集上没有带来类别收益**。

**描述本身（形态/位置/方向/Caption）的事实正确性尚未完成复核**，
本报告只在其完成范围内陈述。

## 3. 训练

- 基座 `Qwen3.5-9B`；`ms-swift`；**语言侧 LoRA**（rank 16 / alpha 32 / dropout 0.05）、
  `target_modules=["all-linear"]`（**必须是列表**）、**视觉冻结**；
  BF16；固定 2 epoch；末步预选；`strict=True`。
- **D / L 逐图输入完全相同**（同题面、同图、同顺序），**只改监督答案**。
- 每组运行内门槛 **13/13 通过**（设备、冻结、LoRA、loss 有限、`lora_B` 更新、
  非零梯度、图像前向、单卡）。

## 7. **更正：lot 不是一图一 lot**（我差点写错）

我曾只看评测 102 行的 lot 分布（102 图 / 102 lot），就推断「lot 由 sample_id 派生
= 一图一 lot = 隔离同义反复」。**错。** 翻到 `data/manifest.jsonl` 才发现：

| 事实 | 值 |
|---|---|
| 晶圆 / 唯一 lot | 5904 / **3822** |
| **单 lot 最多含** | **24 张晶圆** |
| **跨 split 的 lot** | **0 / 3822** |

→ **lot 隔离是真实有效的约束。** 评测 102 恰好来自 102 个不同 lot，
那只是**这批子集**的属性。**别拿子集的形状去断言全局结构。**
