# 旧 7 件与新 1200：分账（Codex 要求「旧7件和新1200分账」）

冻结时刻 2026-10-08。**只读，未改动任何文件。**

## 一、旧件：`GLM/原答.jsonl`

| 项 | 值 |
|---|---|
| 行数 | **7** |
| `item_id` | `wb_001` … `wb_007`（前缀 `wb_`，与新批的 `wbg####` **不同**） |
| 文件 SHA256 前 16 | `0da569fa0299630015b056f82a25a96c` |
| 独有字段 | `answer_sha256` / `answer_time` / `check` / `image_hash_checked` / `model` / `prompt_sha256` / `sample_id` |
| 与新的 1200 按 `item_id` 的交集 | **0** |

**结论**：这是**更早一批**（另一套 `wb_` 编号体系）的产物，
**不并入 1200 的分账**。1200 的分账只统计 172 份 canonical 分片。

## 二、但**图片**层面有 2 件被沿用

| 旧件 | sample_id | 与新批同图 | 答案 |
|---|---|---|---|
| `wb_001` | `wafer_00000042_024` | 无重叠 | — |
| `wb_002` | `wafer_00002434_021` | 无重叠 | — |
| `wb_003` | `wafer_00002498_020` | 无重叠 | — |
| `wb_004` | `wafer_00002517_007` | 无重叠 | — |
| `wb_005` | `wafer_00003953_007` | 无重叠 | — |
| **`wb_006`** | `wafer_00005178_001` | **`wbg0093`** | **逐字节相同** |
| **`wb_007`** | `wafer_00007258_022` | **`wbg0123`** | **逐字节相同** |

→ **新 1200 里有 2 条是从旧批原样沿用的**（不是重新生成）。
这属于「**保存记录数 ≠ 实际后端调用次数**」的一个具体例子：
磁盘上有 1200 条记录，但其中 2 条并非本批新产生的调用。

## 三、口径提醒

- 这三件事**必须分开报**：
  ① **保存记录数**（1200）② **机械合格数**（556）
  ③ **实际后端调用次数**（**未核，不可知** —— 客户端不会回报真实调用数）。
- 「同图」用 `image_sha256` 判定；**相同图片 SHA 不等于相同晶圆 ID**
  （`wbg0003/0705` 与 `wbg0011/0712` 两组就是同图不同 ID，**不合并**）。
