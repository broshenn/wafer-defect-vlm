# 分片1（12 图）描述事实复核 — 模型复核稿

- **性质**：**模型复核**（Claude 逐张读图 + 像素统计辅助）。**不是人工 gold、不是盲测、不是专家考卷**；不填写任何"人工"栏位。
- **范围**：只核对描述性四字段（`morphology` / `radial_zone` / `clock_direction` / `caption_zh`）与图像事实。**不判类别对错**（材料本来也没有类别；描述正确与否 ≠ 类别正确与否）。
- **图像口径**：黑=晶圆外；绿=合格 die；红=失效 die。**图上方=12 点钟，右方=3 点钟。**
- **方法**：12 张 PNG 全部用图像查看方式实际打开；另以只读像素统计佐证（红占比、红质心钟位、径向十分位分布、角向覆盖/缺口、连通块数与最大块）。统计口径：红=(R>200 且 G<60 且 B<60)，绿同理；晶圆=红∪绿；角度自 12 点顺时针。
- **判定词汇**：形态/位置——支持、基本支持、部分支持/部分吻合、不吻合；方向——适用性（适用 / 不适用）+ 吻合性（吻合 / 部分吻合 / 不吻合 / 未提供）；遗漏与断言——无 / 轻微 / 有。
- 复核日期 2026-10-08；材料：`复核分片/分片1_共12图.json`。
