## 更正 1：原 F1 不是公平对照 —— 用的根本不是同一批图

原报告（`今晚类别RL_20261006_0325/交付报告.md` §1.8）说：
> "F1 取**同样的前 20 张图**、每张**连续重复 4 次**"

**这是错的。** 从 F2 真实的 `reward_audit.jsonl`（80 条）取出实际 20 组 ID 后比对：

| | 类别分布 | 与对方重叠 |
|---|---|---|
| **原 F1 用的 20 张** | **Center ×10 + Donut ×10**（只有两类！） | 8 / 20 |
| **F2 实际用的 20 张** | Near_full×3、Center×5、none×2、Donut×3、Scratch×3、Loc×2、Edge_Ring×1、Random×1 | 8 / 20 |

**只在原 F1 里的 12 张**：`wafer_00000490_013`、`_00004397_009`、`_00017127_015`、
`_00017143_025`、`_00017154_019`、`_00017159_022`、`_00036829_023`、`_00036993_015`、
`_00042291_021`、`_00042347_021`、`_00045349_007`、`_00045899_008`。

**结论：原 F1 与原 F2 训练的是不同的 20 张图，而且原 F1 的图集只有两类。**
§1.8 里"呈现计划已对齐"的说法**不成立**。

## 更正 2：两层打乱都开着，4 份副本在旧 F1/F2 里都被打散了

从两个 run 的 `args.json` 实测（不是推测）：

```
f2_run20:  dataset_shuffle = True    train_dataloader_shuffle = True
f1_sft20:  dataset_shuffle = True    train_dataloader_shuffle = True
```

所以原报告"每张**连续**重复 4 次"描述的是**文件顺序**，**不是实际训练顺序**。
`dataset_shuffle` 先把 80 行打乱，`train_dataloader_shuffle` 再打乱一次，
每个优化步看到的 4 个样本**不是同一张图**。

**这也解释了为什么原报告说"F1 呈现计划对齐 F2"是站不住的**：
即使图集相同，打乱也会破坏分组结构。

## 更正 3：串行不是不公平的理由

原报告 §2 未知项第 7 条写："F1/F2 未并行（同一张卡串行）……不宣称公平预算优胜"。

**这个说法本身不成立。** 串行与并行**不决定对照是否公平**；决定公平的是：
同一起点、实际 ID 与顺序、呈现次数、可训练模块、计算成本。
本轮的缺口是**呈现证据**，不是卡的使用方式。此条更正。

## 更正 4：9 步同分、全程均值、末步不等于全程

原报告只报了"末步 reward 0.25 / std 0.5"。从 F2 真实审计（80 条）复算：

- **20 组中 9 组组内奖励同分**（第 3、4、8、10、11、13、14、16、18 步，1 起数）
- **11 组存在类别奖励差异**
- **全程平均奖励 = 0.5625**
- 末步 `[1.0, 0.0, 0.0, 0.0]`

末步 std 非零**不能代表每一步都有类别优势**。同分步仍可能有 KL 项引起的更新，
**不能称"参数完全不更新"**。未连续同分 5 步，停止条件确实未触发。

（这三项与 Codex 独立复算**逐项一致**。）

## 更正 7：资源账的口径 —— 不能朴素相加

原报告给"累计 162.81"，那是**朴素相加**（六卡 71.26 + 占位 49.62）。
占位进程与六卡训练/推理**在 GPU 0、GPU 1 上时间重叠**，
按**每张卡的占用区间并集**重算后：

| 卡 | 并集分钟 | 说明 |
|---|---|---|
| GPU 0 | 26.23 | 占位段 01:07:24–01:23:15 与训练段 01:23:34–01:39:01 **不相交**，相加 |
| GPU 1 | 33.77 | 占位段 01:07:24–01:41:10 **完全覆盖**训练段，只算一次 |
| GPU 2–5 | 各 10.38 | 只有训练段 |
| **第一轮小计** | **101.52** | 朴素相加会是 120.88，**多算 19.4 分钟** |

**重算后累计 153.37 / 180**（含 1 分钟无日志失败的保守预留）。
详见 `资源账_进程与设备分钟.json`。**进程分钟与物理设备分钟分列，不混称。**
