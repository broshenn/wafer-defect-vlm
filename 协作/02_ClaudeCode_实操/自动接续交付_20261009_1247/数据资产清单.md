## 〇、一句话

四个数字**不是四批并列的数据**，而是一条**包含链**：

```
WM811K 公开集（抽样渲染 5904）
        └─ train+val 子集 5315
              └─ 旧 SFT train 划分 4292        ← 旧一轮训练用的
                    └─ 本轮训练池 3072          ← 本轮 L/D 实际训练
                          └─ 「训练缺口 1200」   ← WorkBuddy 补描述，全部 ⊂ 3072，未入训
```

**关键更正（必须一起说）**：`1200` 的两份文件（`包说明.json`、`执行总指令.md`）
分别写成「来源池 = 4292」和「与 3072 并列」，但独立审计实测
**`1200 ∩ 3072 训练池 = 1200 / 1200`**（`协作/02_ClaudeCode_实操/描述事实验收_20261008_1911/B_WorkBuddy合并/WorkBuddy现状审计.md:74`）。
→ **`1200` 不是新的唯一晶圆，它整批落在已训的 3072 之内**；
按「不把派生内容当新增唯一晶圆」的纪律，**它不能与 3072 相加计作资产**。
