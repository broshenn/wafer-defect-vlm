## 5. 可复用的学校推理命令

**环境**（已固定，勿升级）：

```
/WS/envs/wafer/bin/python
torch 2.6.0+cu124 · transformers 5.16.1 · ms-swift 4.5.3 · peft 0.20.0
trl 0.29.1 · accelerate 1.15.0 · datasets 4.8.4 · msgspec 0.22.0
```

**关键环境变量**：`IMAGE_MAX_TOKEN_NUM=256`

**父进程按 GPU UUID 锁卡**（不要写进 Python，写在 shell 里）：

```bash
CUDA_VISIBLE_DEVICES=<GPU-UUID> python ...
```

**基座/合并模型的推理**（必须显式给 model_type 与 template_type，
否则合并目录可能判别失败）：

```bash
CUDA_VISIBLE_DEVICES=<GPU-UUID> IMAGE_MAX_TOKEN_NUM=256 \
  /WS/envs/wafer/bin/python eval_unified.py \
  --models R0=/WS/checkpoints/Qwen3.5-9B-R0merged \
  --outdir /WS/checkpoints/eval_X
```

**LoRA 的推理**（挂在 R0 上，用 `::` 分隔）：

```bash
CUDA_VISIBLE_DEVICES=<GPU-UUID> IMAGE_MAX_TOKEN_NUM=256 \
  /WS/envs/wafer/bin/python eval_unified.py \
  --models R2=/WS/checkpoints/Qwen3.5-9B-R0merged::/WS/checkpoints/rl90_R2/v0-XXXX/checkpoint-90 \
  --outdir /WS/checkpoints/eval_X
```

**评测协议**：`temperature=0`、`max_tokens=64`、推理 `seed=3407`，
严格 JSON 解析（拒绝重复键/截断/多对象/尾随文本），九类固定 Macro-F1。
