即三个候选不是共同错向某一类。

## 4. 用量与成本 **[事实]**

| 候选 | prompt | completion | **其中推理** | 推理占比 | 图片 token |
|---|---|---|---|---|---|
| deepseek | 8,946 | 62,326 | **60,112** | **96.4%** | 未拆分 |
| kimi | 10,980 | 35,746 | **33,426** | 93.5% | **259**（直接给出） |
| qwen | 8,892 | 42,955 | **41,073** | 95.6% | **198**（直接给出） |
| 合计 | 28,818 | 141,027 | 134,611 | — | — |

**总 token 169,845**，其中 **推理占 79%**。

**图片 token 与文本的比例**：一张 448×448 PNG = **198（qwen）/ 259（kimi）** 个图片 token；
同一请求的提示词文本 token 是 296（qwen）。
→ **图片 : 文本 ≈ 1 : 1.5**；图片只占单次请求总 token 的约 1/8。

**百炼免费额度**：kimi + qwen 合计 98,573 token = **额度的 9.9%**。余量约 10 倍。

## 5. 一个必须记下的发现：`kimi/kimi-k3` 与 `kimi-k3` 不等价 **[事实]**

| 模型 ID | 结果 |
|---|---|
| `kimi/kimi-k3` | **HTTP 400** `"The product is not activated..."` |
| `kimi-k3` | **HTTP 200**，返回 `model: kimi-k3` |

**同一账号、同一密钥、同一请求体**，只有 ID 不同。
→ 印证了 Codex 早先的判断：「文档目录本身不能证明两者在用户账号下可互换」。
**换 ID 是用户明确授权后才做的**，不是自动回退。
