## 一、枚举与复核口径

- 五维（形态 / 位置 / 遗漏 / 断言 / 格式）只接受：`SUPPORTED` / `PARTIAL` / `CONTRADICTED` / `UNCERTAIN` / `MISSING`（整字段为空、未答）。
- **负向维度极性**（遗漏 / 断言 / 格式）：`SUPPORTED` = 没有该问题（干净）；`CONTRADICTED` = 有该问题。
- **方向两列**：`applicable`（该图该不该有方向：整圈环、全片随机、中心团簇、无缺陷 → false）；`verdict` ∈ {SUPPORTED, PARTIAL, CONTRADICTED, UNCERTAIN, **NO_ANSWER**}——`NO_ANSWER` = 模型没给方向（与“给了但错”分开；`applicable=false` 时的 NO_ANSWER 属预期不答）。
- 本轮复核采用的严重度校准：
  1. **孤立大结构的整块遗漏**（如某图左缘约43die实心团块）记 `CONTRADICTED`——依据冻结回归先例“漏掉左缘红色块 = 有重大遗漏”；
  2. **中等规模随机丛集遗漏**（约34die、占红<10%）记 `PARTIAL`（轻微）；
  3. **背景稀疏散点**占红像素约≥30% 且完全未提及 → `PARTIAL`；
  4. **方向容差**：与结构质心相差 ≤ 约0.5小时记 `SUPPORTED`，否则 `PARTIAL`；
  5. `clock_direction` 写成**字符串 "null"**（而非 JSON null）→ 格式 `CONTRADICTED`（冻结回归先例）；给出数值尺寸违反题面“不要给出未经验证的数值尺寸”约定 → 格式 `PARTIAL`；
  6. 表述中**明确否认图中可见结构**（“无明显聚集”等）→ 除遗漏外另记 断言 `PARTIAL`。
