# 分片1 描述事实复核（12 图，已盲）——模型复核草稿

- **性质**：本文件是**模型复核草稿**，不是人工 gold，未填任何「人工」栏位。材料为盲件（甲/乙两个匿名答案集），**未读取盲号对照 key**，不对答案来源身份作任何推断。
- **判定依据**：逐张用 Read 打开 PNG 目视核验 + 像素统计。红≈(255,0,0)、绿≈(0,255,0)，die=红+绿像素；径向三带按 1/3 半径划分；12 扇区从 12 点起顺时针每 30°；连通块为 4-连通；网格尺寸由最近邻格块游程估计（约 26×26 至 64×64，各图标明）。
- **图像约定**：黑=晶圆外，绿=合格 die，红=失效 die；上方为 12 点钟、右方为 3 点钟。
- **方向判定规则**：整圈环 / 全片随机 / 中心团簇 / 无缺陷 / 近全覆盖 → 方向**不适用**；只有偏离中心的局部聚集才判「适用」再判吻合。环形/全片图不强造唯一方向。
- **范围**：只判断「描述与图是否相符」，不判类别对错。
