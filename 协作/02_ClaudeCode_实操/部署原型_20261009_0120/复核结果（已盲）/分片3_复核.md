# 分片3 描述事实复核（12 图，已盲）——模型复核草稿

- **性质**：本文件是**模型复核草稿**，不是人工 gold，未填任何「人工」栏位。材料为盲件（甲/乙两个匿名答案集），**未读取盲号对照 key**，不对答案来源身份作任何推断。
- **判定依据**：逐张用 Read 打开 PNG 目视核验 + die 级像素统计。统计方法：按最近邻块反解出原始 die 网格（12 图重建重合率 0.973–0.988，网格可信），再计算红 die 占比、径向三带密度（0–0.4R / 0.4–0.8R / 0.8–1.0R）、12 时钟扇区密度（12 点=0°、顺时针）、8-连通块。
- **图像约定**：黑=晶圆外，绿=合格 die，红=失效 die；上方为 12 点钟、右方为 3 点钟。
- **方向判定规则**：整圈环 / 全片随机 / 中心团簇 / 无缺陷 / 近全覆盖 → 方向**不适用**；只有偏离中心的局部聚集才判「适用」再判吻合。环形/全片/近全覆盖的图不强造唯一方向。
