# 启动包说明（可启动代码 + 固定依赖/权重/题面指纹）

## 一、包里有什么

| 文件 | 作用 | sha256（见 `指纹.json`） |
|---|---|---|
| `wafer_service.py` | HTTP 服务 + 真实 ms-swift 推理后端（`/health`、`POST /predict`、`/`） | ✓ |
| `demo.html` | 上传/结果页面（由服务根路径返回） | ✓ |
| `replay_selftest.py` | 对真实 HTTP 服务回放 36 图并落指标 | ✓ |
| `test_cpu_contract.py` | 6 项 CPU 输入/输出契约检查 | ✓ |
| `prompt_7f.txt` | **冻结七字段题面**，服务启动时校验哈希 | ✓ |
| `schema_check.py` | **冻结检查器**，服务启动时校验哈希 | ✓ |
| `样本清单.json` | 36 图清单（含 `图号/sample_id/公开类别/图sha256`） | 仅供**测试脚本** |
| `图/` | 36 张 448×448 PNG | 逐张 sha256 在清单里 |

**服务进程不加载标签、旧答案或案例缓存** —— 清单里的 `公开类别` 只被
`replay_selftest.py` 用于类别评分。

## 二、怎么启动

```bash
export CUDA_VISIBLE_DEVICES=<本人获准卡的UUID>
export IMAGE_MAX_TOKEN_NUM=256 PYTHONNOUSERSITE=1
export WAFER_CHECKER=/WS/deploy/schema_check.py

python /WS/deploy/test_cpu_contract.py          # 6 项 CPU 契约

python /WS/deploy/wafer_service.py   --model /WS/models/Qwen3.5-9B   --adapter /WS/adapters/D-N3072-3407   --tag D-N3072-3407   --prompt /WS/deploy/prompt_7f.txt   --checker /WS/deploy/schema_check.py   --out /WS/deploy/runtime_records   --host 127.0.0.1 --port 7860 --max-runtime-seconds 2700
```

## 三、怎么关闭

`--max-runtime-seconds` 到点自动 `os._exit(7)`；也可 `pkill -f wafer_service.py`。
**进程退出不等于平台停止计费。**

## 四、依赖（与已验证环境一致）

Python 3.12.3 · **torch 2.8.0+cu128** · transformers 5.16.1 · peft 0.20.0 ·
ms-swift 4.5.3 · Pillow · numpy —— **不重建环境、不重下模型、不装 vLLM、不量化**。

## 五、复跑自测

```bash
python /WS/deploy/replay_selftest.py --url http://127.0.0.1:7860   --samples /WS/deploy/样本清单.json --images /WS/deploy/图 --out /WS/deploy/selftest2
```
脚本**拒绝覆盖已有结果**（`--out` 目录里已有 `http_replay.jsonl` 会直接报错退出）。

## 六、两个不允许的用法

1. **不要**把 `样本清单.json` 的 `公开类别` 接进服务 —— 那是评分用的，不是模型输入。
2. **不要**把 `runtime_records/` 里带 `format_changes` 的 `result` 当作原模型格式成绩 ——
   **原答在 `raw_answer` 里**，改动单独记在 `format_changes`。
