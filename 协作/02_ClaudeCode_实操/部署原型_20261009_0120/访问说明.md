# 推理原型：访问说明（**仓库版，已脱敏**）

> 真实的实例端点与口令**只保存在仓库外的私人配置**里，本文件不记录。
> 下面用占位符 `<实例端口>` / `<实例主机>`。

**服务监听 `127.0.0.1:7860`，只绑本地，公网不可达。**
服务窗口 `--max-runtime-seconds 2700`（45 分钟），到点自动 `os._exit(7)`。

---

## 一、怎么看这个服务（两种方式）

### 方式 A：SSH 隧道（推荐）

在自己电脑的终端里，把原来的 ssh 命令加一个 `-L` 参数：

```bash
ssh -p <实例端口> root@<实例主机> -L 7860:127.0.0.1:7860
```

保持终端开着，浏览器打开 **http://127.0.0.1:7860** 。

### 方式 B：租用平台的控制台「自定义服务」

控制台的自定义服务一般映射 **6006** 端口；本服务按合同跑在 **7860**。
若要改用控制台入口，需要把 `--port` 改成 `6006` 再重启
（代价是多花一次约 10 秒的模型加载）。

---

## 二、页面上怎么用

上传 **448×448 PNG** —— 必须是**项目渲染器生成的黑/绿/红三色晶圆 BIN 图**
（黑=晶圆外，绿=合格 die，红=失效 die）。

页面显示六项：**类别、主要形态、径向位置、钟点方位、中文描述、不确定项与需复核提示**。

**会被明确拒绝的输入**（返回 4xx，不是静默出错）：

| 输入 | 返回 |
|---|---|
| 空请求 | `413 请求应包含不超过4MB的PNG` |
| 损坏文件 | `422 PNG无法解码` |
| 灰色 / 非三色图 | `422 本原型支持黑/绿/红三色BIN图，请使用项目渲染器` |
| 非 448×448 | `422 请上传448×448的晶圆BIN PNG` |
| 带透明通道 | `422 本原型不支持透明PNG` |

---

## 三、接口（脚本调用）

```bash
curl http://127.0.0.1:7860/health
curl -X POST --data-binary @图.png -H "Content-Type: image/png" \
     http://127.0.0.1:7860/predict
```

单 GPU **串行**：同时来的第二个请求会拿到 `429 模型忙，请稍后重试`。

---

## 四、关闭

```bash
# 到点会自动退出；也可以手工停
ssh -p <实例端口> root@<实例主机> "pkill -f wafer_service.py"
```

⚠️ **服务进程退出不等于平台停止计费** —— 实例的关机请在平台控制台操作，
计费状态以控制台为准。
