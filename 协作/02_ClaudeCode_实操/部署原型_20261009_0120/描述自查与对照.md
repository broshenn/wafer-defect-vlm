# 描述自查与对照（部署原型 vs 外部 GLM）

> **全部是模型复核草稿，不是人工 gold。**
> **本项目已决定不做真人复核（2026-10-08），真人两列永久留空。**

## 口径

1. **盲评**：复核者只看到图片 + 两个匿名答案集（甲/乙），
   **看不到来源、看不到公开类别**；来源映射只在汇总阶段折回。
2. **判据**：从句级 + 否定感知（问题词前 6 字内有否定则不算问题），**混合单独一档**。这套判据是 Codex 指出「无重大遗漏被判成有问题」后修正的。
3. **六维极性不同**：「形态支持 / 位置吻合 / 方向适用吻合」→ 支持才是干净；
   「是否遗漏 / 是否断言 / 格式问题」→ **「无」才是干净**。
4. **不判类别对错**；公开类别只用于类别评分，不作为描述 gold。

## 三、结论（**对部署模型不利，但这是真的**）

**在固定 36 图、同一七字段题面、同六维判据、盲评条件下**
（复核者只看到图 + 两个匿名答案集，**看不到来源、看不到公开类别**）：

| 维度 | **部署服务 `D-N3072-3407`**（干净/有问题） | **外部 GLM**（干净/有问题） |
|---|---|---|
| 主要形态是否有图像支持 | 26 / 7 | **30 / 6** |
| 位置是否吻合 | 28 / 8 | **31 / 3** |
| 方向是否适用、吻合 | **36 / 0** | 35 / 0 |
| 主要结构是否遗漏 | 24 / 10 | **28 / 7** |
| **是否无依据断言** | **26 / 10** | **35 / 1** |
| 格式约定问题 | 35 / 1 | 35 / 0 |
| **小计（216 项）** | **175 干净 / 4 混合 / 36 有问题 / 1 不确定** | **194 / 3 / 17 / 2** |

### 可以说

- **在「描述事实」这一项上，本轮盲评里部署模型不如外部 GLM**：
  干净项 175/216（81.0%）对 194/216（89.8%）。
- **差距最大的是「无依据断言」**：部署模型 26/10，GLM 35/1 ——
  即部署模型更常写出图上支持不了的断言。
- **两者在「方向」与「格式」上基本持平**（部署模型方向 36/0，是它最干净的一项）。
- **这与类别结论方向相反**：类别上 `L` 91.7% ≫ GLM 33.3%，
  但**描述上部署的描述模型并没有更好**。
  → **「类别强」不能推出「描述强」**，这两件事在本轮被实测分开了。

### 不可以说

- **不可以说「部署成功 = 能力相当」** —— 恰恰相反，本轮描述对照**不支持**这个说法。
- **不可以把类别的 91.7% 移到描述上** —— 那是 `L` 模型在**类别专用题面**上的成绩，
  与描述无关。
- **不可以说 GLM 全面更好** —— 类别上差得很远（33.3% vs 91.7%），
  且外部真实后端与采样参数未知。
- **这是模型自查**，执行者继承编排会话上下文，**不是人工 gold**。

### 一个必须记的复核材料缺陷（**我造成的**）

**第一轮复核的材料没有盲** —— 我在构造复核材料时只剔除了「盲号→来源」的映射，
**漏剔了 `来源` 和 `公开类别` 两个字段**，等于把答案身份直接印在材料里。
分片1 的复核者主动报告了这一点，分片3 甚至据此去解读"谁更好"。

我因此**把第一轮整体作废**（存于 `复核结果_第一轮_未盲（作废）/`），
重建了**只有图号、图片、盲号与四个描述字段**的材料（已脚本核验无泄漏），
**重跑了三个全新复核会话**。上面的数字来自**第二轮**。

### 观察到的具体问题类型（来自三个分片的原文）

- **否认或误读主结构**（最重）：把占红量 55%–71% 的连续块/边环写成「随机稀疏」；
- **密度用词失真**：「稀疏」用于红占 30%–47% 的图；也有把 46.5% 红说成「绝大部分」而
  53.5% 绿说成「少量」（占比说反）；
- **径向定位偏内**：「中心区域」用于实际全片或外圈偏多的图；
- **钟点偏差**：小簇图中偏差约 16°–25°；
- **模板化复用**：多处 `morphology` 与 `caption_zh` 逐字复用、跨图同句。
