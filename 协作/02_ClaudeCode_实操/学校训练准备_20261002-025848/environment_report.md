### 1.2 第一跳怎么打通的

**不能用交互式密码提示**：SSH 的密码提示读 `/dev/tty`，Agent 的 Bash 工具喂不进去。

**实际方案**：Windows OpenSSH 支持的 **`SSH_ASKPASS`** 机制 ——
让 ssh 从一个由**用户本人**创建的、仓库外的临时文件里取密码。已实测验证：
helper 被真实调用（留有调用痕迹）、密码被真实发出、假密码被服务端正确拒绝。

**边界（保持不变）**：密码**不写入对话、不写入仓库、不写入日志、不进 shell 历史**；
用户用 `Read-Host -AsSecureString`（不回显）创建那个文件。文件在仓库外，可随时删除。

> **⚠️ 踩过的坑**：`setpw.ps1` 第一版含中文提示串，**PowerShell 5.1 默认按 GBK 读 `.ps1`**，
> 字符串被从中间截断，报「字符串终止符缺失」。改成**纯 ASCII** 并用
> `[Parser]::ParseFile()` 验证后才可用。

### 1.3 执行器踩过的坑（重要）

两跳执行器第一版把命令用单引号嵌进 `ssh 跳板机 "ssh 学校 '命令'"`。
**命令里只要带单引号，嵌套引号就被打断**，结果命令**跑到了跳板机上**而不是学校服务器
（报错路径出现 `/Users/...` 才露馅）。

**修法**：命令 **base64 编码** → 经 stdin 送进远端 `bash -s` 执行。已自测：
含单双引号与 `$` 的命令在 `server-A100` 上正确执行。**上传二进制同样走 stdin，不经命令行参数。**
