## 四、执行方式

1. **开一个新的父会话**，不要在旧会话里继续（旧会话上下文会污染）。
2. 父会话下开 **最多 3 个 GLM 子 agent** 并行。
3. **每张图一个 item**：读图 → 按上面的提示词作答 → 把**原答**写到
   `<item_id>_raw.json`（内容就是那七字段的 JSON 对象本身）。
4. **单图失败隔离**：某一张读不出或答得不成形，就把它单独记下来跳过，
   **不要重试、不要影响同批其它图**。
5. **系统级错误停新调度**：如果出现输入读不到、视觉链路异常、写入失败、
   模型套餐异常或**任何额外付费提示**，**立即停止派发新任务**并报告。
6. **额外付费 0**：只用客户端已有套餐，**不换模型、不新增付费**。
