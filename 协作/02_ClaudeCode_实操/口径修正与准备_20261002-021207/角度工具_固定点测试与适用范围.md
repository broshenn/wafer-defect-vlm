# 角度工具：固定点圆心漂移测试与适用范围

**起因**：`踩雷记录` **B43**（Codex 指出）。
**结论**：Codex 指出的问题**成立**，我复现了它的每一个数字，并发现**影响比"测试写错"更深一层** ——
原设计的容差单位与圆心漂移单位**对不上**，导致默认容差对典型晶圆几乎没有保护作用。

---

## 1. B43 说的那个错，我复现了

**原测试**（`angles.py` v1 的 demo §3）保持 `dr/dc` 不变、只改传入的圆心。
而 `clock_angle_deg` 内部是"圆心 + 偏移"生成缺陷点 ——
**点和圆心一起平移，相对位置不变**，所以测的是**平移不变性**，不是"圆心漂移下缺陷点归属是否稳定"。

**Codex 的固定点用例，我在本机逐位复现**（72×72 网格，缺陷点固定在 (36,46)，圆心 (36,36)，d = 10 格）：

| 圆心行漂移 | 角度 | 扇区 | on_boundary |
|---|---|---|---|
| 0 | 90.0000000000° | 4 | True |
| ±1e-12 格 | 90.0000000000° | 4 | True |
| ±1e-9 格 | 89.9999999943° | 4 | True |
| **+1e-6 格** | **89.9999942704°** | **3** | **False** |

**与 Codex 给的数字一致。** 也就是说：**我声明的 1e-6 度吸附容差，挡不住 1e-6 格的圆心漂移。**

---

## 2. 为什么挡不住：单位不匹配（这是比测试写错更根本的问题）

**[事实/推导]** 点距圆心 `d`（格），圆心沿垂直于该点的方向漂 `δ`（格），
角度改变约 `δ/d` 弧度 = `(δ/d)·(180/π)` 度。

要让容差 `τ`（度）真正挡住 `δ`（格）的漂移，需要：

```
d  >  δ · (180/π) / τ
```

**[事实]** 代入本工具的默认值 `τ = 1e-6°`、`δ = 1e-6 格`：`d > 57.3 格`。
而本库晶圆的半径**通常只有 12–36 格**（`matrix_shape` 边长 22–150，取半）。
⇒ **默认容差对典型晶圆几乎没有保护作用**，只是数值噪声级的。

**所以 B43 的后果不止"测试白测了"** —— 它同时暴露了 v1 的**设计缺陷**：
用一个固定度数去防一个以格为单位的不确定度，两者没有固定换算关系。

---

## 3. 改法：逐点容差 + 圆心不确定度显式声明

`angles.py` 现在：

- 新增 `guard_tolerance_deg(distance_px, center_uncertainty_cells, H, W)`：
  该点适用的容差 = `max(基础容差, (δ_px / d_px)·180/π)`，`δ_px` 取两轴中较大的换算（保守）。
- 新增 `sector_of_point(row, col, center_row, center_col, …, center_uncertainty_cells=0.0)`：
  **按绝对坐标**取点，圆心单独漂移 —— 这才是"圆心漂移稳定性"要测的东西。
- `angular_histogram` 改用绝对坐标，并把 `center_uncertainty_cells` 写进输出。
- `angle_config.json` 新增 `center_uncertainty_cells_default = 0.0`，并写明：
  **默认 0 是"假定圆心精确"的声明，不是自动推断**；圆心若来自拟合或有已知漂移，
  **必须**声明这个数，否则边界点会在容差之外翻转而报告不提示。

---

## 4. 稳定性的**语义**（不靠放大容差凑绿）

容差按定义 = 漂移 δ 时的**最坏**角度偏移。所以：

- **保证范围**：圆心漂移 **严格小于** δ 时，边界点的扇区归属不变；
- **漂移正好等于 δ 时**，由构造决定落在边界上（既不保证稳定、也不保证翻转）——
  **这是定义使然**。v1 的测试要求"漂移 = δ 时仍稳定"，等于要求浮点比较的运气；
  **我没有通过放大容差去让那条变绿**，而是把语义写准，并把测试改成在 δ 的 50% 与 99% 处验稳定。

**实测（`angles.py --demo` §3/§3b/§3c）**：

```
[3]  固定点 (36,46)、圆心 (36,36)，d=10 格：
       漂 0 / ±1e-12 / ±1e-6 格 → 扇区恒为 4（v1 在 +1e-6 时翻成 3）
[3b] 解析式 d > δ·(180/π)/τ：
       τ=1e-6°、δ=1e-6 格 ⇒ 需 d > 57.30 格   ← 远超本晶圆半径 12–36 格
       τ=1e-6°、δ=1e-3 格 ⇒ 需 d > 57295.78 格
       τ=1e-3°、δ=1e-3 格 ⇒ 需 d > 57.30 格
[3c] 声明 δ 后，在 50%·δ 与 99%·δ 漂移下：扇区集合均为 {4}（δ = 0 / 1e-6 / 1e-3 三档全过）
```

## 5. 适用范围与**不**适用范围（明确写清）

| 适用 | 不适用 |
|---|---|
| 圆心由调用方给定、且**声明了不确定度 δ** 的场景 | 圆心未知或未声明 δ —— 工具按 0 处理，**不提示**，边界点可能翻转 |
| 把扇区当**辅助诊断字段**使用 | 把扇区当**严格金标**或**新的奖励项**（B37/B38 仍未解决，旧字段未回写） |
| 距离圆心 `d` 较大的点（`d` 越大，同一 δ 下角度越稳） | 圆心附近的小 `d` 点：容差按 `1/d` 放大，方向本身不可靠 |
| 渲染图方向下的方位判断 | 物理方位判断 —— 我们没有 die 的物理尺寸与间距 |

**本工具暂不升级为严格金标；旧 `features` 不回写。** 与 Codex 裁决 §3③ 一致。
