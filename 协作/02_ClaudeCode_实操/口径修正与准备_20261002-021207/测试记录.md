## 2. 各项覆盖了什么（逐项写清，便于抽查）

### 2.1 `wafer_png_v2.py --self-test`
- **样本**：宽度 W = 29 / 31 / 33 / 41 / 42 / 63 / 72 / 150 / 200 / 255 / 300 / 400 / 447 / 448。
- **做法**：把源格号用**两个通道**编码（R=低字节、G=高字节）渲成 448×448，读回每个目标像素的源格号，与 `source_index_for` 比。
- **为什么用两通道**：第一版把源格号塞进 `uint8`，W>256 时 `np.arange(W, dtype=uint8)` **回绕**，
  于是"测试失败"其实是**测试自己溢出**。已记入 C 类教训。

### 2.2 `test_wafer_png.py`
- **B1 范围内**：13 个形状，边长 22–200，随机矩阵 → 渲染 → 反解 → **逐格比对**。全 True。
- **B2 超范围**：`(255,255)`、`(300,299)` —— **期望失败**，用来把"本方法不是任意分辨率可用"钉成一条测试。
  两者都返回 `roundtrip_validated=False` 且逐格不一致，**与预期相符**。
- **C 真实九张**：反解形状 vs manifest `matrix_shape` 9/9 一致；往返像素差全 0。

### 2.3 `check_answer_v3.py --self-test`
- 26 条路径，覆盖退出码 0/2/3/4/5/6/7/8 全部八档。
- **重点两条**（v2 会崩溃的）：`defect_class=[]`、`radial_zone={}` → 都返回 **5**，不再抛 `TypeError`。
- 合法用例：`unknown` 类别、`7点钟`、`7/8点钟`、`uncertainty` 空串、字段顺序不同 —— **都通过**。
