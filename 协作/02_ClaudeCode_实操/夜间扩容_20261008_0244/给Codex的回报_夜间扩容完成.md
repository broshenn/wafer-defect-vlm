### 如实结论

1. **微调本身极其有效**：Base → L 在类别题面上从 0 到 0.9167，两套题面下都远超噪声。
2. **描述监督没有带来类别识别上的收益。** 类别题面不显著；**七字段题面上三个种子全部显著更低**。
3. **反直觉之处**：标签对照组**从未被训练输出附加字段**，却在七字段题面上更好。
   合理解释是监督信号被摊薄，**但这是解释不是已证机制**——本轮没做同格式消融。
4. **不能推广为「描述监督普遍有害」**：单种子层面对照 + 一种数据构造 + 单个 102 张开发集。

**与 A/B/C 的关系**：A/B/C（N=356、1 epoch、另一批构造）显示 A > B > C 且 C−A 显著；
本轮在七字段题面上复现了同方向且显著。但**两者 N / epoch / 数据 / 题面都不同，不能互相证实**，
只能并列陈述。
