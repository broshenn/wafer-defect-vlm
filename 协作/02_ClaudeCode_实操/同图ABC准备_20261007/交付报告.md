## 3. 三组的构造

**三组分类答案统一取公开原始 `failure_type`，未用教师预测替换。**
教师给出的类别另存（见 §6），本轮不下发。

| 组 | 监督目标 | 目标中位长度 | 序列≈ |
|---|---|---|---|
| **A** | `{"defect_class":"…"}` | 8 token | 349 |
| **B** | `+{"geometry":{radial_zone, defect_ratio, extent_r:null, clock_direction:null}}` | 37 token | 378 |
| **C** | `+{"caption_zh":"…"}` | 34 token | 375 |

**统一题面（三组相同输入，255 字符）**：

```
这是公开晶圆 BIN 图。黑色为晶圆外，绿色为合格 die，红色为失效 die。
请判断图中**主要缺陷图案**的类别，从 Center、Donut、Edge_Loc、Edge_Ring、Loc、
Near_full、Random、Scratch、none 中选一个。
只输出一个 JSON 对象，不写推理过程或 Markdown。
`defect_class` 为必填，取值为上述九类之一；无法可靠判断时填 "unknown"。
可以在同一个对象里附加你**从图中实际看到**的判读依据字段；没有把握就不要写。
```

### 3.1 B 的几何字段（定义明确、源码核过）

| 字段 | 定义 | 来源 | 备注 |
|---|---|---|---|
| `radial_zone` | 主要缺陷相对晶圆半径所处区域 | `manifest.features.radial_zone` | 以拟合圆心的归一化半径 r/R 划分，**不涉及渲染像素** |
| `defect_ratio` | 失效 die 占**晶圆内有效 die** 的比例 | `defect_count / valid_count` | **不是整个矩阵面积**；保留 4 位小数 |
| `extent_r` | — | — | **null**：尺寸无可靠 gold，本轮不下发数值 |
| `clock_direction` | — | — | **null**：扇区边界数值敏感，未修复前不下发 |

**明确区分**：
- 用的是**原矩阵 die 统计**（`valid_count` / `defect_count`），**不是渲染像素统计**；
- **全体红点质心不等于主缺陷簇位置** —— 因此本轮**没有**把质心当成位置 gold；
- **未把几何分类器的预测类当 gold**。

## 4. 题面与解析协议（避开一个直接错误）

**新解析器 `abc_parse_v2.py` 自测 14/14。**

核心差别：**旧严格解析器要求对象只能有一个字段**，
那会把 C 组的附加描述**全部判成 `extra_fields` → 0 分**。
新解析器：

- 只从**唯一** `defect_class` 字段取主分类答案；
- **允许**附加字段（geometry / caption_zh / morphology / radial_zone …）存在；
- 仍**拒绝**：重复键、截断、多对象、尾随文本、非九类且非 unknown 的取值。

自测里专门放了一条「**旧解析器会误杀**：带附加字段的 C」用例，确认新解析器给出正确类别。

## 10. 预算估算（**不是实耗**）

**实测锚点**：今天 R1（类别-only，90 步，序列约 320 token，单卡）= **7.84 分钟**训练。

| 组 | 步数 | 序列≈ | 训练 | 含加载 |
|---|---|---|---|---|
| A | 89 | 349 | 8.5 | 10.0 |
| B | 89 | 378 | 9.2 | 10.7 |
| C | 89 | 375 | 9.1 | 10.6 |
| **三组合计（单卡串行）** | | | | **31.3** |
| 基座 + A/B/C 四模型同题评测 | | | | **13.0** |
| **合计** | | | | **≈ 44.3** |

**当前余额 51.92 → 能在余额内完成，余量 7.6 分钟。**

**必须说清楚的口径**：
- **信息种类与答案长度同时改变** —— A 目标 8 token、B 37、C 34，
  **不能假装三组等 GPU 成本**。
- 但序列长度被 **196 个 image token 主导**，三组只差 7%–8%，
  所以**设备分钟相近**；**真正差的是监督 token 量，不是墙钟**。
- 这是**估算**；**不自动扩累计上限**。
