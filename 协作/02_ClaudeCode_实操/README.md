## 我做过、值得记住的三条

1. **`0.6693` 是"答题者"的准确率，不是"判卷器"的** —— 本计划里 `verifier` 一词被用在两个不同东西上（`踩雷记录` B27）。
2. **`0.6693` 用了全部 4720 条标注**，不是零标签成绩（`踩雷记录` C16）。
3. **我在读 `config.json` 时打印了 `apiKey`**（`踩雷记录` C 类 + `AGENTS.md` §18.5）。**做任何输出之前先界定输出范围。**
