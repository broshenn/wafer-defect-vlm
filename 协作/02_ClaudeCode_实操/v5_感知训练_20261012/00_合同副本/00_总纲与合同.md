## 3. 输出格式 v5（训练与评测共用，逐字固定）

### 3.1 主题面 `PROMPT_V5`（会话 A 写入 `A_数据/prompt_v5.txt`，记 SHA；所有主任务行的 user 内容 = `<image>\n` + 该文本）

```
这是公开晶圆 BIN 图，黑色为片外，绿色为合格格点，红色为失效格点。
先输出一行测量，再输出一个 JSON 对象。不写 Markdown，不写推理，不输出其他内容。
第一行严格按此格式：<measure>red_ratio=X.XX; zone_frac=A.A,B.B,C.C; R1=D.D; R2=E.E</measure>
red_ratio：红点占全部红绿格点的比例，保留两位小数。
zone_frac：全部红点分别落在 center、middle、edge 三个径向区带的比例（晶圆归一化半径三等分），各保留一位小数。
R1：全部红点绕晶圆中心的单向角向集中度，0 到 1，保留一位小数。
R2：全部红点的轴向（相对两侧）集中度，0 到 1，保留一位小数。
没有红点时，red_ratio、zone_frac、R1、R2 全部填 0。
第二行输出 JSON，严格包含六字段：
defect_class：Center、Donut、Edge_Loc、Edge_Ring、Loc、Near_full、Random、Scratch、none 或 unknown。none 表示未见可辨缺陷模式，不表示红点为零。无法可靠判断时填 unknown。
coverage_band：zero、under_5pct、5_to_under_20pct、20_to_under_50pct、half_or_more 或 unknown。分母为图中所有红绿格点；half_or_more 只表示红点占半片及以上，不等于几乎全片。
red_mass_zones：按 center、middle、edge 顺序排列的数组，或 unknown。总红点至少3个时，区内至少2红点且占全部红点至少10%才纳入。无红点填空数组；少量证据不足填 unknown。
angular_type：single、opposed、nondirectional 或 unknown。指全部红点相对晶圆中心的角向聚集；opposed 表示相对两侧聚集，不表示一定有一条穿中心划痕。
clock_sectors：整数数组，上方12点、右方3点、顺时针，12个扇区；single填1个扇区，opposed填2个相对扇区，其余填空数组。证据不足不要强猜。
uncertainty：中文简短说明，确定时为空字符串。
```

### 3.2 目标答案（assistant 内容）= 两行
```
<measure>red_ratio=0.27; zone_frac=0.0,0.3,0.7; R1=0.6; R2=0.4</measure>
{"defect_class":"Edge_Loc","coverage_band":"20_to_under_50pct","red_mass_zones":["middle","edge"],"angular_type":"single","clock_sectors":[1],"uncertainty":""}
```
- 第二行 JSON 用 `json.dumps(obj, ensure_ascii=False, separators=(",", ":"))`，键顺序固定为 `defect_class, coverage_band, red_mass_zones, angular_type, clock_sectors, uncertainty`。
- 两行之间只有一个 `\n`。

### 3.3 测量值的来源（全部来自程序，`g = measure_v3(matrix)`）
| 测量 | 取值 | 格式 |
|---|---|---|
| red_ratio | `g["coverage"]` | `f"{x:.2f}"` |
| zone_frac | `g["radial"]["zone_frac"]` 的 center/middle/edge | 各 `f"{x:.1f}"`，逗号相连 |
| R1 | `g["direction"]["R1_concentration"]` | `f"{x:.1f}"` |
| R2 | `g["direction"]["R2_axial"]` | `f"{x:.1f}"` |
- `g["status"] == "no_red"` 时：`red_ratio=0.00; zone_frac=0.0,0.0,0.0; R1=0.0; R2=0.0`。
- 舍入一律用 Python 的 `format`（银行家舍入无关紧要，但全项目统一用这一种）。

### 3.4 六字段参考 = `core_v3.reference(g, public_class)`；合成图没有类别，用同一映射但 `defect_class` 不出现在任何监督里（合成图只用于原子问答，见 5.3）。

### 3.5 解析规则（训练奖励、评测打分共用，会话 B 实现为 `parse_v5`）
1. 先用 v3 的 `strip_envelope`（剥完整空 `<think></think>` 和单个代码围栏）。
2. 剥完后必须匹配正则（DOTALL）：
   `^<measure>red_ratio=(\d\.\d{2}); zone_frac=(\d\.\d),(\d\.\d),(\d\.\d); R1=(\d\.\d); R2=(\d\.\d)</measure>\s*\n\s*(\{.*\})\s*$`
3. JSON 用 v3 的 `parse_raw_strict`（拒重复键、拒 NaN）后过 v3 的 `schema_errors`。
4. 任一步失败 → 格式不合法。同时单独记录"原始全文是否以 `<measure>` 开头"（原始口径），不参与奖励。

## 5. 训练数据规格（会话 A 生成）

### 5.1 旋转增广
- 只用旋转，不用镜像。`np.rot90(matrix, k=-1)` = 顺时针 90°；k=-2 为 180°，k=-3 为 270°。
- 旋转后用 `matrix_to_image(m_rot, 448)` 渲染，再 `measure_v3(m_rot)` **重新计算**全部几何（不做标签换算）。
- 命名：`<sample_id>_r090.png`、`_r180.png`、`_r270.png`。类别沿用原图公开类别（九类都旋转不变）。
- **程序等变性自检**：对 TRAIN_POOL 里原图方向为 single 的全部样本，检查 r090 的扇区 = 原扇区 + 3（模 12，0 记 12）；coverage_band、red_mass_zones 应完全不变。报告一致率；不一致的逐条列出（边界并列导致的 unknown 属正常，单独计数）。一致率低于 95% → 按 0.4 决策表处理，写 DECISIONS.md。

### 5.2 合成图（只用于原子问答，不用于类别）
- 底图：TRAIN_POOL 里 `failure_type=="none"` 且 `coverage < 0.02` 的矩阵，把红格（值 2）全部改成绿格（值 1），取前 300 个（按 sample_id 排序）。
- 坐标：用几何 v2 模块的 `_ellipse_of` 与 `_normalized_uv` 得到每格的归一化 `(u, v)`，`r = sqrt(u²+v²)`，钟点角 `deg = degrees(atan2(v, -u)) mod 360`（12 点 = 0°，顺时针）。
- 七种图案，`rng = np.random.default_rng(3407)`，每张随机选一种，所有红点只落在有效格内：

| 图案 | 参数 | 规则 |
|---|---|---|
| local_blob | r0∈[0.2,0.85]，θ∈[0,360)，半径 s∈[0.08,0.20]，填充 p∈[0.6,1.0] | 到中心点 (r0,θ) 距离 < s 的格以概率 p 变红 |
| edge_arc | θ 中心，跨度 30°–120°，r∈[0.85,1.0]，p∈[0.6,1.0] | 角度在弧内且 r 在范围内的格以 p 变红 |
| ring | r_in∈[0.3,0.85]，宽 w∈[0.05,0.15]，p∈[0.6,1.0] | r∈[r_in, r_in+w] 的格以 p 变红 |
| line | 过点 (r0∈[0,0.5], θ)，方向 φ∈[0,180)，半宽 0.03，长度 L∈[0.6,1.6]，p∈[0.7,1.0] | 到直线距离 < 半宽且沿线投影在长度内的格以 p 变红 |
| center_blob | 半径 s∈[0.15,0.35]，p∈[0.6,1.0] | r < s 的格以 p 变红 |
| random_scatter | p∈[0.05,0.30] | 每个有效格以 p 变红 |
| blob_plus_line | local_blob + line 各一次 | 叠加 |

- 每张再叠加背景噪声：每个有效格以 q∈[0,0.01] 变红。
- 标签：对合成矩阵 `measure_v3` 重新计算（程序真值）；图案名只存为元数据 `pattern`，**不是类别**。

## 7. 奖励函数 v5（会话 B 实现 `reward_v5.py`，夜跑前冻结 SHA）

格式不合法（第 3.5 节）→ 奖励 −1，不再算其他项。

合法时，各分量：

| 分量 | full / noproc | binary |
|---|---|---|
| class | 对 +1；错 −1；`unknown` +0.2 | 同左 |
| coverage | 档位序 `zero<under_5pct<5_to_under_20pct<20_to_under_50pct<half_or_more`：相同 1，相邻 0.5，其余 0；模型答 unknown 0 | 相同 1，否则 0 |
| zones | 集合 Jaccard；两边都空集 = 1；模型答 unknown 0 | 集合完全相同 1，否则 0 |
| angular | 类型相同得 0.6；扇区分 0.4×s：参考 single 时 s = 1（扇区相同）/0.5（差 1 个钟点）/0（其余）；参考 opposed 时把两个扇区按模 6 比较，规则同上；参考 nondirectional 时 s = 1 当且仅当模型类型为 nondirectional 且扇区为空；模型类型 unknown 时 s = 0 | 类型相同且扇区集合相同 1，否则 0 |
| measure | 四项平均：`max(0,1−|Δratio|/0.10)`、`1−L1(zone_frac)/2`、`max(0,1−|ΔR1|/0.3)`、`max(0,1−|ΔR2|/0.3)`；Δ 对 `measure_exact` 算 | 四项平均：`|Δratio|≤0.02`、`L1≤0.2`、`|ΔR1|≤0.1`、`|ΔR2|≤0.1` 各记 1/0 |
| consistency | 两项平均：①由模型自己的 red_ratio 按档位边界（0、0.05、0.20、0.50）推出的档位是否等于它答的 coverage_band（red_ratio=0 对应 zero）；②由模型自己的 zone_frac 取"≥0.1 的区带"推出的集合是否等于它答的 red_mass_zones（答 unknown 时此项记 0） | 同左 |

适用性：参考的 coverage_band / red_mass_zones / angular_type 为 unknown 时，该分量不计（从权重里移除后重新归一）。

权重（合法时）：

| 模式 | class | coverage | zones | angular | measure | consistency |
|---|---|---|---|---|---|---|
| full | 0.30 | 0.15 | 0.15 | 0.15 | 0.15 | 0.10 |
| binary | 0.30 | 0.15 | 0.15 | 0.15 | 0.15 | 0.10 |
| noproc | 0.30 | 0.15 | 0.15 | 0.15 | 0 | 0 |

`R = Σ(w_i × c_i) / Σ(w_i)`，其中 class 分量取值 [−1, 1]，其余 [0, 1]；被移除的分量不进分母。

奖励类签名与 v3 相同：`__call__(completions, reference_json=None, sample_id=None, **kwargs)`，长度不齐或缺列直接抛异常；每条记录审计（sample_id、原文、是否有空 think 前缀、原始口径是否合法、各分量、总奖励）。模式由环境变量 `WAFER_REWARD_MODE ∈ {full, binary, noproc}` 决定，未设置就抛异常。

### 8.1 评测矩阵

| 模型 | SELECT200 | TEST | ROT200 | SHUF100 |
|---|---|---|---|---|
| 原生基座（主题面） | ✓ | ✓ | ✓ | ✓ |
| L（自己的类别题面） | ✓（类别） | ✓（类别） | — | — |
| S0、S1、S2、S3、S4、S1p | ✓ | ✓ | ✓ | ✓ |

解码：`temperature=0.0`，`max_tokens=384`，`seed=3407`；原答保存原始全文与剥包装后两列。S3 及其派生评测用 `_x2` 数据。

### 8.2 指标
- **几何**（参考不为 unknown 的样本上）：coverage 精确率与"相邻内"率；zones 精确率与平均 Jaccard；angular_type 正确率；扇区正确率（只在参考为 single/opposed 的样本上，同时报告这类样本的数量）；measure 四项的平均绝对误差。
- **GeoScore**（主指标）= mean(coverage 精确率, zones 精确率, angular_type 正确率)。
- **类别**：准确率、九类 Macro-F1、逐类召回。
- **格式**：剥包装后合法率、原始口径合法率。
- **一致性**：consistency 两项的平均（同奖励定义）。
- **旋转等变**（ROT200，只算原图与旋转图都格式合法的样本）：coverage 与 zones 预测不变的比例；在原图预测为 single 的样本上，旋转图预测扇区 = 原预测 + 3 的比例。
- **去图**（SHUF100）：GeoScore；同时给出"永远答多数类"的基线（用 TEST 参考分布算）。
- **HOLD56 / CONF120 子集**：几何与类别各报一遍。

### 8.3 统计
- 配对 bootstrap，按 `lot_name` 成组重采样，10000 次，`numpy.random.default_rng(3407)`，报差值点估计与 95% 区间。
- **预注册比较对**（只有这些对写"有效 / 无差异"结论）：
  - S1−S0（课程）、S2−S1（视觉侧）、S3−S1（分辨率）、S1−S4（数据引擎）、S1−S1p（种子方差参照）
  - R-full−R-SFT（**RL 主结论**）、R-full−R-binary（距离奖励）、R-full−R-noproc（过程奖励）、R-full−R-fullp（种子方差参照）
- 写"有效"的条件：区间不含 0。否则写"本批未观察到差异"。
- **RL 主结论成功标准**：R-full 的 TEST GeoScore 高于 R-SFT 且区间不含 0，同时 R-full 的类别 Macro-F1 不比 R-SFT 低超过 0.03。
- 一切不达标结果如实报告，不调奖励、不换种子、不挑 checkpoint。

### 8.4 诊断（第 7 卡）
- **线性探针**：原生基座的视觉编码器输出（merger 之后的图像 token）做平均池化 + 4×4 空间平均池化，拼接后 PCA 到 256 维；用 TRAIN_POOL 原图 2000 张训练 `LogisticRegression(max_iter=2000)`，在 TEST 上预测 coverage_band、red_mass_zones（整个集合当一个类别）、angular_type；报告准确率与多数类基线。
- **解读规则（预注册）**：若探针在 TEST 上三字段平均准确率 ≥ S1 的 GeoScore − 0.05，判"几何信息在视觉特征里基本可读，瓶颈偏语言侧"；否则判"视觉特征不足"。再看 S2−S1 的方向是否与此判断一致，如实报告一致或不一致。
- **CNN**：torchvision ResNet18（不用预训练权重），输入 224×224（448 图最近邻缩小），TRAIN_POOL 原图训练 20 轮，Adam 1e-3，batch 64，seed 3407；TEST 上报类别准确率与 Macro-F1。torchvision 不可用时改用 4 层卷积小网络，并在报告写明。
