## 一、这是什么项目

**晶圆 BIN 图缺陷理解**，基座 `Qwen/Qwen3.5-9B`，训练框架 `ms-swift 4.5.3`。
数据是 **WM811K / LSWMD** 公开数据集：5,904 张晶圆图、9 类缺陷
（Center · Donut · Edge_Loc · Edge_Ring · Loc · Near_full · Random · Scratch · none）。

每张图是一格格的 die：**黑=晶圆外，绿=合格，红=失效**。渲染成 448×448 无损 PNG。

**要回答的问题**：少量可靠示例能不能让模型学会基本判读；
把判读条件写成可核对的规则，能不能减少对教师模型描述的依赖。

**仓库是公开的**：`github.com/broshenn/wafer-defect-vlm`（本地 `D:\pycode\晶圆图研究`）。

## 八、踩过的坑（别重踩）

1. **`target_modules` 传字符串会让冻结静默失效**。ms-swift 的 `get_target_modules()`
   第一行 `if isinstance(args.target_modules, str): return` —— `freeze_vit`/`freeze_aligner`
   **根本不被读取**，LoRA 会插进 ViT。实测：字符串 → 视觉侧 220/553 可训练；**列表 → 0/333**。
   **CLI 会解析成列表（安全），只有 Python API 传字符串才中招。**
2. **`CUDA_VISIBLE_DEVICES` 写在 `import torch` 之后等于没写**。必须在**父进程 shell**设，
   脚本内断言 `device_count == 1` / `world_size == 1`。
3. **`EXIT=0` 不等于无编码错误**。ms-swift 会把编码失败的行**悄悄换样本**，
   整体仍退出 0。要单独 grep `errors in the template.encode`。
4. **合并目录 ms-swift 判别不出 model_type**：`save_pretrained` 会用新版 transformers
   重写 config（`vision_config.model_type` 变 `qwen3_5_vision`），且判别还看**目录名**。
   合并后要改名为 `Qwen3.5-9B-xxx` 并**显式传 `model_type`/`template_type`**。
5. **`EncodePreprocessor` 不产出 labels**，`data_collator` 又要求
   `pixel_values`/`image_grid_thw` 是 tensor。要算监督区间就**自己算**：
   同一行把 assistant 清空再编码得 prompt 长度，其后即被监督段（可复现、已抽验）。
6. **两跳脚本必须走 base64**，否则命令里的引号会在跳板机上被解析，**命令会跑在 Mac 上**。
